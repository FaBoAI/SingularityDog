# 新30Hz・4系統CANの人支持による短い荷重確認

既存R3の箱支持試験は変更しない。ここは別ソースで凍結・配置・再計測するための独立した準備コードで、既定はファイルだけを読むPLANである。現在のR3キットや旧50Hzの実行許可を転用しない。

## 範囲

- 2人で役割を分担する。1人が胴体の全重量を支え続け、もう1人が端末と40V遮断を担当する。手は最後まで胴体から離さない。
- 新しい8秒上限の現在位置保持。学習済み30Hzモデルは入力を検証・推論するが、送る目標は取得した現在位置で、学習目標の割合は0。
- Kp6/Kd0.15、変位1°、測定速度0.25rad/s、推定PDトルク0.2Nm、指令速度1°/s、加速度5°/s²は旧人支持レビューの上限を保つ。他の計測・温度・電圧・関節範囲も拡大しない。
- 音声説明と短い開始音を聞いた後、手を離さず支える力を少し緩める時間は最大0.5秒。独立タイマーが全支持への復帰を要求する。音声の完了後の新しいEnterだけが復帰の申告になる。
- 全周期と返信の上限は33.333334ms。入力取得から全軸書込みは20ms、合図に使う直前の完全保持記録の鮮度も20ms。開始・返信の特例は持ち込まない。
- 重さの移動、接地、自立は操作の申告から推定しない。動画と実物の評価を別に記録する。立位・歩行・手離しはこの範囲に含まない。

## 独立ゲート

新しいソース一式と実際に選択したrunnerのSHAを固定する。現在の全12軸UID・角度・同一起動とモーター電源区間・枝・IMU候補・30Hzモデルを元の受信記録へ結ぶ。新ソースの501周期STOP代理、全12軸200ms通信断保護、新ソースの2秒ゼロゲインType1の実送受信を確認する。先に通った箱支持Type1は、その元のcontractとsourceで確認する補助資料である。

新しい現在姿勢で全支持・4足接地・干渉なし・2人の役割・動画・聞こえる音声・同じ可視端末・撤去と復帰のリハーサルを直接記録する。物理条件は現在の人の回答からだけ記録し、テストや過去の回答から作らない。

## ファイル

- `profile.py`: 別schemaの数値契約、元記録とソースを検査するファイルだけの準備。
- `supervision.py`: 可視端末・音声完了・0.5秒独立タイマー・古いEnter破棄・復帰確認・異常時キャンセル。
- `runner.py`: 既定PLANの独立dispatch。実行時も新opaque証拠を再検査し、別キットの専用control loopだけを選択する。
- `type1_runner_hooks.proposed.patch`: 既存runnerとの差分を記録した提案。独立namespaceに別名で展開し、元R3は変更しない。旧箱支持の既定経路は保持し、新しいopaque準備だけを別modeとして扱う。
- `transport_hooks.proposed.patch`: 新独立adapterのKp6上限と別sealの提案。旧Kp3 adapterは変更しない。native本体はsessionごとのgain上限を再検査する。提案の段階ではライブラリを配置・実行しない。
- `runner-proposal-manifest.json`: 提案元と結果のSHA。実機への配置済み、実出力の許可済みを意味しない。
- `test_profile.py / test_supervision.py / test_runner_proposal.py`: ファイル・疑似受信・PTYだけの検証。実機の前段資格にはならない。

提案diffの元SHAは、作成時の履歴ソースを指す。現在の箱支持ソースへ自動で適用・追従しない。テストだけが、凍結済みの独立ソースからdiffを逆適用して元SHAを照合し、再適用した結果が同じ凍結ソースになることを検査する。履歴ソースと現在ソースを混同せず、実行コード・manifestのSHAや実機の資格は書き換えない。

## 別キットを実行する前に

提案diffと専用foregroundの接続をレビューし、別の新しいキットに適用する。専用`type1_transport.py`と`foreground.py`の独立ソースは実装済みである。R4の凍結・配置・実native receiptの検証・新ソースの前段と人支持での実測が完了するまでは、実機試験が可能という資格を付けない。その実ソースとnativeの生成物を凍結して読み戻し、新しい計測記録を作る。R3の元ソース・過去原票は書き換えない。ソース未配置、runner接続未確認、前段の原通信不足などの残件がある準備は実行へ渡せない。

全支持復帰の合図を出す処理に失敗しても、CANのキャンセルと全軸STOPはEnterを待たない。STOP返信が確認できない場合は40Vを遮断し、人が全支持を保ったまま箱へ戻す。
