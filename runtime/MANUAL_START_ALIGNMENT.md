# 右後脚の開始位置を手で合わせる

`manual_start_alignment` は、右後脚3関節の現在角度と固定参照との差を同時に表示する読取り専用ツールです。毎秒5回、新しい角度を読みます。モーターの駆動、原点の書換え、基準角の自動更新は行いません。

## 手順

1. 胴体を支持台に載せ、脚を床や台から離します。モーターが脱力し、手で動かせることを確認します。
2. Jetsonで `~/dog-align-rr` を実行し、脱力・支持状態を確認してEnterを押します。標準の表示時間は90秒です。
3. ID7＝足先側、ID8＝上脚、ID9＝付け根。表示される「差」が0°に近づく方向へ、必要な関節だけ手でゆっくり調整します。符号はモーターの生角度で、上下・前後を直接表しません。接触や抵抗があれば無理に押さず終了します。
4. 3つとも±0.5°以内になったら手を離し、数値が保たれるか確認します。手を離すとずれる場合は、そのまま報告してください。無理に繰り返したり、別の支持物を脚へ挟んだりする必要はありません。
5. 表示が終わるかCtrl+Cで終了した後、記録を確認します。次の駆動試験では改めて静止・手離し・開始位置を確認します。

±0.5°は比較試験用の候補条件です。表示が範囲内になっても、校正の完了、静止の証明、駆動開始の承認にはなりません。4脚すべてをL字に揃える作業でもありません。

## 実装の範囲

固定参照は元記録・個体・起動セッション・前後USB物理経路と対応付けます。ID7〜9の識別と位置読取りだけを許可し、CANの書込境界で通信種別0／17の正規の要求か再検査します。

最大120秒、要求数も制限し、欠測・古い値・不正返信・接続先や起動セッションの変更で終了します。前の値を新しい測定として表示せず、自動再送や自動駆動へ切り替える処理もありません。既存CANツールと同じ排他を使うため、駆動試験や通信計測と同時に実行しません。

停止モードをこの読取りだけで証明することはできません。操作者による脱力確認と、通信で得られた角度の情報を区別します。

## 配置・検証

9月24日、Jetsonへ固定参照付きの専用パッケージを配置し、6ファイルのハッシュを照合しました。オフライン28テストと独立レビューが合格。無駆動の10秒確認では153要求・応答、50組の3軸表示を完了し、エラーなし、ポート終了・排他解放を確認しました。開始位置を合わせる手動作業はこの表示確認とは別です。

このランチャーは当日の起動セッション・個体・USB経路に紐付きます。再起動や部品交換後に参照が一致しなければ、先に再照合します。
