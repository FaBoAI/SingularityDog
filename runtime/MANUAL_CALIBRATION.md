# Enterで進める手動校正

Jetsonの端末で案内された姿勢に手で合わせ、Enterで12関節をまとめて保存します。
1脚5姿勢、全4脚20記録。目安は約3分ですが、時間制限はありません。
支持台で脚を浮かせ、モーターが脱力した状態で行います。

```sh
# Jetsonへログインした端末で実行
~/calibrate-dog

# 1本だけやり直す場合（FR右前、FL左前、RR右後、RL左後）
~/calibrate-dog --leg FR
```

一般のソース配置から実行する場合は、runtimeディレクトリーで
`python3 -m singularitydog_hw.manual_calibration --execute`。
`--execute`なしは全姿勢の案内表示だけです。
実行には対話端末が必要で、SSH越しなら通常のSSHログインまたは`ssh -t`を使います。

| 操作 | 結果 |
|---|---|
| Enter | その姿勢を約1秒保持して記録。問題がなければ次へ |
| s | その位置の記録を飛ばす。校正候補に不足として残る |
| q / Ctrl-C | 終了。取得済みの記録は残る |

読み取りは各軸5サンプルが標準です。読み取り中に打ったEnterは次の姿勢へ持ち越しません。
位置ばらつき・同じ脚の別軸のずれが大きい場合は、姿勢を調整してEnterで再記録します。
失敗した記録も消さず、別の番号へ保存します。通信失敗は全体を中断します。

## 各脚の5姿勢

犬自身から見た右・左です。**全ての脚で、L字の球は顔側へ向けます。**

| 順序 | 手で合わせる姿勢 | モデルの目安（付け根 / 上脚 / 膝） |
|---|---|---|
| 1 | 上脚は鉛直下、膝から球中心は顔側へ水平。付け根横リンクも水平 | 0 / 0 / −90° |
| 2 | 上脚・膝位置を保ち、膝から先だけ回して球を約2cm下げる | 0 / 0 / −80° |
| 3 | L字に戻し、膝の直角を保って上脚を顔側へ約10°傾ける。下脚も一緒に回す | 0 / −10 / −90° |
| 4 | L字に戻し、脚のL字を保って付け根から外へ約10°開く | 右脚 −10・左脚 +10 / 0 / −90° |
| 5 | 最初のL字へ戻す。再現性を確認 | 0 / 0 / −90° |

約10°は方向確認の目安で、角度計で測った値ではありません。接触や抵抗がある位置は無理に合わせず飛ばします。

## 全脚を同時にL字で保持する必要はありません

校正中は案内された1脚だけを保持し、ほかの脚は自然に垂らして構いません。
全脚の記録後の姿勢照合も、支持台上で自然に垂れた状態を使います。

1. 各脚の保存済みL字基準を保持し、静止した現在の12軸を読み取る。
2. `q候補 = q_L + sign候補 × (raw現在 − raw_L)` で現在のモデル角度候補を計算する。
3. 同じ姿勢の側面と正面の写真で、付け根・上脚・膝・足先をモデルの関節位置と比較する。
4. 追加照合が必要な関節だけ、その1脚を手で別の見やすい姿勢へ合わせて撮影・再記録する。

自然に垂れた姿勢を角度ゼロとは扱いません。URDF範囲外でも角度を切り詰めたり、
折り返し補正や原点の自動修正を行ったりしません。斜め写真だけで精密な角度や全脚の整合は保証できません。
この照合はモーター保持を使わず、候補を実機駆動設定へ自動適用するものでもありません。

## 保存結果

`~/singularitydog-logs/manual-calibration-日時-識別子/`に作成します。

- `session.json`: 各姿勢の案内・観測・再試行履歴・原点/符号の候補。
- `RESULT.md`: 12関節の候補一覧と未確認事項。
- `001-fr-l/raw/`等: 機器応答を含む元の記録。
- 各記録の`pose/`: 元のL字との比較。

候補の式は既存の校正文書と同じ **q_model = sign × raw + offset**、角度単位radです。
モデルとの関節対応・角度の精度・可動域・電源再投入時の連続性は未検証です。
値を制御設定へ自動適用せず、`approved_for_runtime`、`zero_verified`、`sign_verified`は常にfalseです。
ID11は旧個体に値飛びがあったため、交換を照合する記録がなければ符号・原点候補を保留します。
交換後は`~/.config/singularitydog/id11-replacement.json`の非公開記録から交換前後のログ・ハッシュ・個体UIDを検証し、確認した新UIDについてだけ、新規セッションの候補生成を許可します。
旧UIDや別の未確認個体、旧個体と新個体を混在させた記録は採用しません。品質判定は交換前と同じです。
交換した左後脚の取り直しは`~/calibrate-dog --leg RL`で行います。

モーターへの送信は識別とパラメーターの読み取り（Type0/17）のみです。
駆動・停止・原点書き換え・位置の自動復帰は行いません。別の駆動プログラムとの同時使用は避けます。
写真撮影はこの端末ツールには含みません。生ログと個体情報はGit管理外に保存し、公開しません。
