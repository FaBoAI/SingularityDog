# ID7出力角とCAN角度の写真照合

`~/dog-id7-photo-pair` は右後脚ID7を手で2姿勢へ動かしたとき、写真A/Bと`0x7019`の読値を対応付ける。CANの送信は識別と位置の読取りのみ。モーターの有効化、移動、ゼロ変更、校正適用は行わない。

1. 機体を支持台に載せ、脚・配線と床・台の離隔を確認する。QDDは脱力し、40Vは通信のためOnにする。異常時は40VをOffにする。
2. Jetson端末で `~/dog-id7-photo-pair` を実行する。
3. 回転軸の正面から、黒いQDD本体の固定目印、金属出力部と一緒に回る黄色い部材の目印、回転中心が同じ写真に入るように**写真A**
を撮る。撮影後、姿勢を保ったまま端末でEnter。写真名は分かれば入力できる。
4. ID7足先側だけを、抵抗のない範囲で手で少し動かして止める。カメラの向きをできるだけ変えず、同じ3点を**写真B**に撮る。姿勢を保ったままEnter。
5. 完了時に端末に出る保存先と写真A/Bを照合する。写真上の2姿勢の相対角とJetsonの`raw_position_change_deg`を比べる。写真の撮影だけでは校正を更新しない。

生記録はJetsonの `/home/jetson/singularitydog-logs/RO-id7-photo-pair-*` に保存する。結果ステータスは `RECORDED_REVIEW_REQUIRED` で、実機制御への適用には物理角の独立確認が必要。
