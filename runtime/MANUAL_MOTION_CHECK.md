# 選んだ脚の位置・速度を手動で照合する

停止中にもRS05の速度値が揺らぐため、実際に手で動かしたときに位置値が追従するかを確認します。
L字の再校正ではありません。現在の自然な姿勢から、右前脚の3関節を1つずつ小さく動かします。
モーターの駆動、停止指令、原点変更、設定書き込みはありません。CANはType0/17の読み取りのみです。

## 手順

2026-09-21のJetson配置では、`~/dog-check-fr`で起動できます。ソースのハッシュを確認してから新しい非公開フォルダーへ記録します。

支持台上で4脚が自由に動き、モーターが脱力していることを確認します。
ほかの駆動・校正ツールは終了してください。電流の読取値0だけでは脱力を証明できません。

1. 右前脚の足先側ID1、中央ID2、付け根ID3の順に表示します。
2. 手を離してEnter（`y`でも可）。最初の3秒は触らずに待ちます。準備の質問への誤入力では質問だけを繰り返します。
3. 「記録開始」の表示後8秒間、指定関節を手で5〜10°程度ゆっくり往復させます。抵抗や接触があれば中止します。
4. 表示された関節が動いたことを目視で確認できたら`y`を入力してEnter。判別できなければ`n`。空欄や誤入力では質問だけを繰り返し、取得済みデータを保持します。自動的に確認済みとは扱いません。
5. 手を離し、自然に完全に落ち着いたらEnter（`y`でも可）。さらに3秒記録して次の関節へ進みます。

取得時間は3関節で42秒、手合わせを含め約1〜2分が目安です。`q`またはCtrl+Cで終了できます。
このツールにはモーターを停止させる機能もないため、異常な駆動があれば操作者が電源を切ります。

```sh
python3 -m singularitydog_hw.manual_motion_check \
  --execute-readonly \
  --expected-uids /path/to/private-identities.json \
  --output /path/to/new-private-observation
```

実行指定なしでは計画だけを表示します。実行時は対話端末が必要です。
`--motor-id 3`で右前脚の付け根だけを新規記録できます（1=足先側、2=中央、3=付け根）。
Jetsonでは `~/dog-check-fr --motor-id 3`。指定した関節だけの記録完了を表示し、以前の記録との自動結合や全3関節の承認は行いません。
右後脚ID7を読む場合は `--leg RR --motor-id 7 --port /dev/serial/by-path/REAR_USB2CAN_PATH` と指定します。`REAR_USB2CAN_PATH` は現在の後側USB2CANの実際のby-path名に置き換えてください。RR/RLのポート指定は必須で、右前脚用の既定ポートへ接続しません。開始前に選択ポートを計画に表示し、記録にも残します。
同じ個体・同じ起動であることを照合し、通信エラー・不正値・受信した故障や有効状態通知で中止します。
対話中も既存手動校正と共通のロックを保持します。非協調的なプログラムの排除までは保証しません。

## 結果

`summary.json`に動かす前・移動中・手離し後の位置幅、速度RMSなどを記録します。
`events.jsonl`には生の送受信と各標本を逐次保存し、途中失敗も残します。
`position_response_observed`は操作者の目視と数値変化の記録であり、精密校正・静止判定の合格を意味しません。
駆動承認は常にfalse、静止判定は未実施です。次の判定仕様を検討する材料として使用します。

原点・符号の既存候補は上書きせず、写真・個体番号・観測データはGit管理外へ保存します。
