これまでの「旧D17目標へ全12軸を同時に近づける」候補は、そのまま試験できない。ID8/9の1回転差は単なる符号・オフセットで解決したと推定しない。前脚上脚の接触は通信やゲインの調整でも解消しない。

次回の事前準備では、現起動の全12軸UID・生角を1回保存し、角度の枝、校正、前脚付け根を先に水平へ近づけた状態での上脚経路を確定する。通路が空くことを現物で確認できた場合にのみ、支持台上の有限移動を別ランナーで検討する。監査の「10°区間数」は比較表を読みやすくする数で、繰返し駆動計画や所要時間ではない。

現在のrole-group試験は保存時の始点から角度が変わると、その場の現在角を起点に最大10°を再計算する。**同じ起動中でも再基準化後は絶対経路が変わる**ため、以前の `swept_clearance_verified` を引き継がず、その新しい始点からの全経路を確認する。

監査は次のコマンドで再生成できる。入力は保存済みJSONのみで、Jetson・CAN・GPIOに接続しない。

```sh
PYTHONPATH=runtime python3 -B tools/review_standing_route.py \
  --current evidence/stance-rest-after-manual-20260926-r1.json \
  --historical evidence/stand10-geometry-20260926.json \
  --output /tmp/historical-staged-stance-review.json
```

出力は常に `output_allowed: false` で、軌道標本・指令フレームは含まない。現在の機体寸法や配線、印刷部品の剛性、荷重下の隙間はこの監査から確定できない。
