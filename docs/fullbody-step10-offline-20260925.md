# 全12軸・最大10°の同時試験案（無駆動）

直近の現起動試験 `Fullbody-current-hold-boot4aaf-r13` は、約4秒で左前脚ID4の固定目標との差が約1.67°になり、5秒保持を完了せずに停止した。12台のSTOP返信と操作者の異常なしは確認したが、この結果を10°の同時駆動許可には使わない。

現状は[オフライン軌道と監視条件](../runtime/singularitydog_hw/fullbody_step10_plan.py)のみ実装した。12台共通の8秒quinticランプと1秒終端保持、50ms周期・180標本、開始位置から最大10°、各軸の生角度方向を明示する形式である。軌道を作るだけでCANへは送らない。推定方向を自動採用しない。方向が未確定なら計画を作らない。

実機用ランナーを実装・適用する前に、ID4の取付・リンクの遊び・接触を脱力状態で点検し、現在の起動で全12軸の5秒保持を通過させる。さらに12軸の個体ID、移動方向、各リンクの通路、支持台からの離隔、手離し、即時40V Offを確かめる。前後2バスの制御処理では、毎周期全12台の新しい返信を得て各軸の追従差・トルク・故障・速度・温度・通信鮮度を監視し、どれか一つでも外れたら両バスの全12台へSTOPを試みる。STOP返信未確認なら電源遮断を依頼する。ソフト監視値はトルクの物理的な上限を保証しない。

旧r13姿勢の幾何計算から得た仮の立位方向は、ID1から順に `+,+,+,-,-,-,+,+,-,+,-,+` だが、これは現物で確認した生角度方向ではない。4脚を一律に10°動かしても立位にはならず、旧始点から10°だけではID3/9は学習モデルの可動域へ入らない。足先は約31〜37mm下がる計算のため、床・支持台との実際の離隔が必要になる。

この資料とコードは立位・学習済みモデルの適用許可や、実機での追従成功を示さない。
