# L18・第23回：高い前足の挨拶を達成、位置保持は未達

**左前足の足底を150mm以上に保つ高い挨拶と、四足復帰を2周期とも達成した。** 500更新後の `model_499.pt` を36秒評価し、総合判定は未達。最大XY移動6.551cmが5cmの基準を超えた。最終位置は0.914cmまで戻るが、終端だけで合格とはしない。

## 達成した動作と残る課題

立位2秒、支持移動と挙上5秒、手振り4秒、足下ろしと復帰5秒、四足保持2秒の18秒を2周期実行した。参照の足上げ目標は165mm、合格に必要な実測足底の最低高さは150mmであり、同じ値ではない。

| 指標 | 結果 | 判定 |
| --- | ---: | --- |
| 完了した往復 | 2往復×2周期＝4往復 | 達成 |
| 実測足底の床離隔 | 153.290〜167.743mm | 全手振り区間で150mm以上 |
| 高い足を維持した時間 | 4秒×2周期＝8秒 | 全3200標本で成立 |
| 四足復帰の連続保持 | 2.000 / 2.000秒 | 両周期成立 |
| 最大方位ずれ | 4.623° | 5°以内 |
| 最大XY移動 | 6.551cm | 5cmを超過 |
| 最終方位・位置ずれ | +2.957° / 0.914cm | 最大値とは区別 |

手振りの成立には、同じ実測端点が胴体相対Xと初期方位に固定したworld Xの両方で20mm以上動く必要がある。各片道に250ms以上、反転確認に2mmを要求し、胴体の漂流や細かな振動を往復数に含めない。今回の成立した片道は胴体相対で31.987〜32.366mmだった。手振り全区間で残り三足の支持も成立した。

予定された支持移動45mmに対し、位置保持の上限は50mmで余裕が小さい。位置ずれの原因はまだ分離できておらず、支持移動の量・配分と復帰時の安定が修正候補である。

## 学習前後と負荷

同じ高い挨拶の参照で追加学習前の親モデルを評価した際は、足底141.085〜152.166mm、150mm以上を満たす時間は8秒中2.0225秒だった。500更新後は全8秒で成立した。最大方位ずれは8.025°から4.623°、最大XY移動は7.944cmから6.551cmになった。参照・移行時間・報酬・左前脚の残差制限を複合変更しており、各変更の効果を個別に特定した比較ではない。

最終評価の禁止接触と関節速度超過は0標本。最大速度3.221rad/s、最大適用トルク2.140Nm、最大傾き2.249°、最大hは0.6194だった。hはシミュレーションの負荷予算で、温度実測ではない。

**学習中の探索は別の結果。** 2949エピソードが終了し、禁止接触6803環境・物理サブステップ、速度超過68関節・標本、最大速度14.798rad/s、最大h0.8743を記録した。これらを最終評価の接触・速度超過0と混同しない。
