3. **支持台上で有限移動を段階的に実測する。** 前脚付け根の連続5°→10°、必要な関節組、最後に全12軸の固定立位移行・保持をそれぞれ返信、追従、故障、現物の隙間、全軸STOPで判定する。全12軸を現在角から立位へ移す専用ランナーと模擬故障試験はまだ必要。
4. **荷重移行を別試験で確認する。** 無通電着脱リハーサルと支持台上・箱上の短い実駆動保持は全12軸STOPまで確認した。一方、二人支持のr5は8軸の始点差で有効化前に止まった。追加のr1・r2読取りも箱上だったため、人が胴体の全重量を支えた姿勢の基準には使えない。支持台を外す新しい試験では、独立した落下受け、または受け止めと40 V遮断を分担する2人を確保する。現時点は1人在席で独立した落下受けがないため、通電中に支持台を抜く試験は行わない。部分荷重に通っても、支持から完全に手を離す2秒の自立はさらに別試験である。
