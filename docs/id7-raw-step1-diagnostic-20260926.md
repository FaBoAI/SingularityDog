# ID7単軸・最大1°の診断記録

**実機結果（同日追記）：** [r9の記録](../evidence/id7-step1-active-20260926.json)では、支持台上でID7へ中心から+1°の有限軌道を送り、前後各160周期の時点で最終追従差0.5°超により停止した。ID7の角度返信は中心から約±0.022°、最後は0°で、1°到達は確認できない。全12軸のSTOP返信を確認した。操作者は足先側の回転部の動きを目視し、異音・振動・引っ掛かりはないと報告した。目視と角度返信の差を、回転部と固定側の目印、同時の角度・トルク記録で切り分けるまではゲイン・トルクを一律に増やさない。この試験は立位や学習済み方策の試験ではない。

第2°診断は後側ID7の実測が+2.6155°に達し、+2.5°の上限で中断した。直前の位置差は約19.3°/s、Type2の速度報告は一時0.4067rad/sだった。全12台のSTOP返信は確認済み。これは立位動作の成功記録ではない。

新しい `rs05_id7_step1` は、**同一起動の新しい12軸静止窓中心**を使う有限診断である。8秒のquinticランプ＋1秒の保持を50ms周期で送り、ID7だけ最大±1°、他11軸には各中心位置を保持する指令を送る。前後のUSB2CANへ各6台を一括送信し、UID・モード・故障・返信期限・電圧・ウォッチドッグ・50ms期限と全12 STOPを従来どおり確認する。KpはID4/10が4、他は3、Kdは0.15。トルクフィードフォワードは0で、ゲインの増強はしない。

ID7には報告速度と連続する位置返信から計算した平均速度の両方に **0.2rad/s** 上限を設けた。指令追従差と中心からの実測逸脱は各1.5°以下、最終のID7目標差は0.5°以下とし、前回の2°試験より厳しくした。その他11軸の位置・トルク監視を緩めていない。ただし50msの返信間に起きる瞬間的な動きはソフトでは止められないため、支持台と人が操作する40V遮断が引き続き必要である。

旧2°パッケージのレビューやraw中心は再利用しない。新しいreview schema/scope、現起動の12UID、前回ABORT記録のSHA、新しい12軸中心、ID7の物理点検、掃引空間・手離し・即時40V Offの確認を、新しい凍結起動器で独立して照合した。無駆動プリフライト後に上記の限定実機試験まで実施したが、モデル角校正・立位・学習済み方策の許可にはならない。
