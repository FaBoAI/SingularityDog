# 荷重移行リハーサル用の有限現在位置保持候補（2026-09-27）

[候補ランナー](../runtime/singularitydog_hw/rs05_load_transfer_hold.py)は、開始時に12軸から得た生角を固定目標として、前後2本のCANバスを独立したworkerで扱う。時間は2〜15秒で、80 ms周期を予定し、端数は最後に待ってSTOPする。学習済み方策、立位目標、荷重の移し方、ゲインの自動変更、自動再試行は含まない。リポジトリの初期状態は`LIVE_OUTPUT_ENABLED = False`、`preflight_only = True`、`live_output = False`である。個体情報と当日の起動・実測を束ねた非公開パッケージでのみ、支持台上の2秒保持を実行した。部分荷重、自立、学習済み方策の実機試験はまだ成功と判定していない。

試験中は全12軸の新しいType2返信を毎80 ms判定し、mode、fault、位置差、速度、温度、返信トルクを監視する。ゲインは既存のKp3/Kd0.15、または個別審査済みのID4/10のみKp4とする。電圧35〜43 Vとvolatile watchdog読戻し4000 tickは有効化前に全軸で確認し、保持中は各バス1軸ずつ毎周期再確認するため各軸の再訪間隔は480 msである。1周期の処理が80 msを超えれば中断する。成功・中断のどちらも、各workerの`finally`から自分の6軸すべてへSTOPを試み、全12軸の停止返信が揃ったか結果に記録する。STOPと200 ms watchdogだけでは、通信断時の実停止時間や機体の落下防止を証明しない。

Type2返信トルクの上限は実機トルク制限ではなく、超過時に次の動作指令を止める診断値である。候補は各軸の審査済み値を要求し、1.5 Nmより大きい設定を拒否する。この値が接地荷重と機械の連続定格に適するかは未判定である。支持台上での小さい返信トルクから荷重時の必要値を外挿できない。正当な荷重・過渡ピークで1.5 Nmを超えると全12軸STOPし、機体が脱力するため、受け止めをSTOP後まで保つ。必要値が1.5 Nmを超える場合も現場で設定を緩めず、根拠を得てコードと試験を再審査する。結果は常に`standing_allowed: false`、`load_transfer_proven: false`、`self_supported_stance_proven: false`を返す。

ローカルの仮想バス試験は、出力禁止の初期状態、2秒・15秒の完走、12軸STOP、時間とレビューの不一致の事前拒否、故障・欠測・遅延・書込み失敗、電圧・watchdog・トルク監視の中断を確認した。実CANの50 ms無効化r1は初回周期で期限超過し、全12軸STOPした。80 msのr2/r3は各バス25周期を完走。40 V Off中のr6は無応答で駆動前に中断したが、充電後のr7はID3/9だけの約±1回転の角度枝を現物確認付きで認めて完走した。支持台を残した有効化r1は初回周期後に共有返信の更新が遅れたため誤って「古い返信」と判定して中断し、全12軸STOPした。全軸の新鮮さを周期の入口で確認するよう修正したソースの無効化r8と、支持台上の有効化r2は前後各25周期を完走し、全12軸STOPを確認した。有効化r2の最大周期は65.43 ms、最低電圧38.77 Vで、操作者は音声と現物異常なしを報告した。**固定支持台が胴体を支えていたため、荷重支持力の証明ではない。** watchdog遮断の実測、部分荷重、停止時の受け止め、IMUと動画の時刻同期は未検証である。

実機に配置し出力を許可する前に、少なくとも次の証拠と明示的な現場許可が必要である。

1. 現起動で全12軸のUID、FW 0.5.0.13、角度枝、故障なし、電圧、watchdog設定と停止返信を読取り専用で確認し、12軸姿勢と使用するゲイン・時間をその起動に結び付ける。
2. 現起動で手置きした四足姿勢を現物で確認し、床に4足を接地させて支持台上の現在位置5秒保持を通す。手置き姿勢から荷重移行へ進む場合、モーターで立位へ移動する軌道試験を必須とはしない。モーターで姿勢を変える場合に限り、その全掃引の干渉を先に確認する。支持台上の5秒保持は、荷重を足に移せる証拠にはならない。
3. 接地荷重での返信トルク・温度・電圧と機械強度・モーター連続定格を照合し、12軸別の診断上限を確定する。負荷反力を測れない場合は荷重割合を推定値として報告しない。
4. 固定支持台を外す前に独立した受け止め具、または支持担当と40 V遮断担当を分けた人員を用意し、40 V Offで移載・受け止めを通して確認する。有限時間の終端では全12軸STOPで脱力するため、受け止めはSTOP後まで保持する。足先の滑り、配線・固定具との接触、姿勢崩れで即時停止できる配置にする。
5. ソースと依存ファイルのハッシュ、今回の試験時間、個体UID、起動ID、物理確認、故障注入試験を束ねた別レビューを作り、実機ランチャーとログを審査する。レビューには固定立位試験の合格、独立受け止め、40 V遮断担当、無通電の移載練習、接地荷重用の監視値をそれぞれ別の確認項目として記録する。その後にのみソースゲートの変更を検討する。変更直後は出力を段階的に検証し、最初から15秒の荷重移行へ進まない。

4足が床に触れていても、胴体が支持台に載っている間は「接地した支持台上の保持」である。支持を抜いた時間を自立と判定するには、胴体と受け止めの隙間、4足接地、姿勢と高さ、時刻付き12軸・IMU、操作者の現物確認を別に揃える。[自立ゲート](self-supported-stance-gates-20260927.md)のS2〜S4を省略しない。
