## 設計上の検討

以下の各行は検討項目です。すべてを実装・実機検証した意味ではなく、15回のカウントへ追加しません。

| 検討したこと | 得た判断・現在の扱い |
|---|---|
| 外装を先に完成させるか | 歩行に必要な可動域・荷重経路・重量配置を先に決め、外装はシンプルにする |
| 3D プリントと管材フレーム | 印刷品で構造を試作し、管材で胴体の荷重を受ける。印刷できることと折れないことは別の検証 |
| 脚の付け根の固定 | ケースを前後から支える構造と、前後それぞれ複数の固定点を検討。ねじ本数だけで耐トルクを保証しない |
| 関節を太く丸くする | 切欠きや急な断面変化を減らす。ただし駆動部の回転・整備・配線を妨げない |
| 重い部品をフレーム内へ配置 | 重心と支持領域を合わせる。前方の顔部の質量も重心計算に含める |
| 膝と接地点の水平距離を短くする姿勢 | 静的モーメントを下げる候補。可動域、足のクリアランス、自己干渉と同時に比較する |
| 足上げ前の荷重移動 | 支持脚の能力と姿勢制御を評価する。見た目の足上げだけを報酬にしない |
| ばねによる補助 | 今回は採用しない。シミュレーションだけに補助を追加しない |
| より大きな駆動部への変更 | 許可はあるが、まず実際の関節別負荷を調べる。今回の基準動画だけでは付け根の大型化が必要とは判断していない |
| 歩幅・脚幅・姿勢・足形状の変更 | 静的な有利さを候補選別に使うが、最適形状や動的な成功とは呼ばない |
| ネイティブ CAD と衝突形状 | 可視形状だけでなく物理形状を照合。有限個の姿勢で干渉なしでも、全軌道の非干渉は保証しない |
| 位相を持つ参照運動と残差学習 | 参照運動に学習した補正を重ねる方式で GPU 学習・推論・収録を実施。完全にゼロから自由な動作を獲得した方式とは区別する |
| 前進を優先した指令の分布 | 前進の頻度を増やし、前進速度を段階的に上げる。後進・横移動・停止のケースも残す |
| 接地時の速度異常 | 高速記録で再現し、数値設定だけの変更と物理モデルの変更を分けて試した |
| 回転慣性の計上 | CAD の剛体慣性と、関節を相対回転させる内部慣性を区別する。二重計上を避け、エンジンの実値を確認する |
| 成功の見せ方 | 最初の区間を同じ時間・速度で収録。失敗の隠蔽、良い区間だけの選別、時間の水増しをしない |

採用理由を残すときは「仮説 → 変更した変数 → 比較条件 → 実測 → 次の判断」の順に記録します。学習済み重みの転用でも、最適化器や環境状態を初期化したなら完全な再開とは記述しません。

## L07：足上げと足の置き位置を再設計

学習済み方策を固定した15ケースを比較。35mm足上げと関節角・IMUによる足位置補正で、四方向の全脚に13〜14回の15mm足上げを確認した。速度指令だけを増やすと下脚が床へ接触して停止したため、足を片側20mm・30mm外へ置く姿勢を比較した。

20mm案の前進は18.64cm/sだったが、後退・左では後右脚の実関節速度が仮上限を超えた。完走やトルク上限内だけで採用せず、四方向の比較基準は足幅を変えない補正案へ保つ。速度超過を切り落とさず、急な軌道変化・追従・接地滑りを次に調べる。新しい足パッドは別の形状候補で、従来形状の速度を成果として流用しない。[測定値と動画](l07-evaluation.md)。

## L08：周期短縮で500更新、横移動の退行も確認

周期を0.56秒へ短縮し、前進指令を段階的に36cm/sへ。L06の重みから新規optimizerで500更新。 前進29.93cm/s、各方向の各脚19〜20回の15mm足上げ。30cm/sは僅かに未達。左の方向ずれ48.74度、後進の滑りが残る。 同条件で前進27.48→29.93cm/sを確認した一方、左の向きずれは3.95°→48.74°に退行。指令37/38cm/sは改善せず、次は向き保持・滑り・参照遷移を優先します。CPU/JIT一致や評価4方向の完走を、学習の全試行や実機の安全性へ拡張しません。[全結果](l08-evaluation.md)。

## L09：前進の目標を達成し、比較条件の差も保存

指令配分・旋回速度報酬・滑り報酬をまとめて変え、500更新。前進31.87cm/sは短区間の全基準を満たしました。一方、後進・左右の速度はL08から下がり、後進の向き−23.97°、左の向き+29.63°、左右速度は未達です。滑りは前進・後進で減ったものの、全方向・全脚の改善ではありません。

L08とL09の後進・左右では初期の過負荷予算に差がありました。リセット時に古い目標が残る仕組みを数値で再構成しましたが、その計算の直接ログはなく、個別変更の効果や完全同一条件を主張しません。元の結果を保存し、次回に初期状態をそろえた比較を設ける判断としました。[第14回の結果](l09-evaluation.md)。

## L10：左右に旋回できたが、位置保持は未達

IMUから推定する相対方位誤差で並進中の参照を補正し、純旋回指令±0.25rad/sを追加しました。観測を69から74へ拡張し、旧重みを移植して500更新。物理モデルと駆動限界は維持しています。リセット処理を修正して旧L09も撮り直し、全ケースの初期状態を一致させました。制御・観測・報酬・指令配分・学習をまとめて変えた比較で、個別の因果効果は分離していません。

前進32.16・後進10.67・右11.65cm/sは向き・足上げ等を含む開発基準を満たしました。左移動は向きが+0.06°まで改善しましたが速度8.36cm/sで未達。左旋回+106.78°・0.155rad/s、右旋回−148.29°・指令方向0.216rad/sで、最大位置ずれ28.3/19.2cmは両方とも15cm基準を超えます。前進の前左滑りも4.74→14.03cmへ増加。次は左移動、旋回位置保持と左右差、前進滑り、残差飽和を調べます。[第15回の結果](l10-evaluation.md)。
