# 9月29日：固定受けを残した30秒保持の試行

機体は高い箱で胴体を支え、4足を床へ接地させた。全重量を受けられる低い固定受けを胴体の約2〜3 mm下に残す条件で、現在位置をKp 12・Kd 0.15で最大30秒保持する専用版を作成した。これは学習モデルによる立位・歩行ではない。

最初のr56fは、操作者が脚を手で動かした後のID2開始角が保存済みの範囲から約6.5°外れ、有効化前に停止した。姿勢を読み直したr57では、直前の再測定で12軸の変化は最大0.009°、モデル関節範囲内だった。

r57は有効化して開始した。約2秒後に箱を抜く合図を出し、操作者は高い箱を抜いたが、脚に支持力を感じなかった。約6.1秒でIMU加速度ノルムが設定範囲10.5〜10.9 m/s²を外れ中断した。305周期を記録し、全12軸のSTOP返信を確認した。中断後、操作者は40VをOffにして高い箱へ戻した。足先の滑り・接触の定量判定と荷重割合は記録からは確定できない。

保持中の実測トルクの最大絶対値は約0.1055 Nm、推定PDトルクは最大約0.0820 Nm、関節移動は最大約0.396°だった。箱を抜く前の保持目標は現在角で、関節の角度差がほぼゼロだった。従って、現在の1.0 Nm監視上限を単に上げても脚に荷重を移す指令にはならない。低い固定受けが胴体を受け、脚の荷重支持は実証できなかった。合図後のEnter記録もないため、高い箱を抜いた正確な時刻はログから確定できない。

次は箱を抜かずに、4足の足先を下へ送る**明示的な小変位目標**を作り、脚の追従・トルク・胴体と箱の隙間を横動画で確認する。D17 URDFと今回の開始角を使ったオフライン逆運動学では、胴体を名目上0.5 mm上げる目標に必要な膝側の最大回転は前脚約1.26°／1.39°、1 mmでは約2.60°／2.89°、2 mmでは約5.56°／6.33°。これらは幾何計算であり、実荷重や実変位の保証ではない。操作者は40V Offで前脚膝側を約6°手動で動かし、接触がないと回答した。

次の実出力はまず0.5 mm相当から、箱を残し、低い固定受けも残して行う。現在のKp・トルク監視値で追従と荷重変化を測り、監視上限に達する場合のみ、実測とQDD仕様に基づいて段階的に再設定する。IMU加速度ノルムは、箱の入れ替え時に短い鉛直加速度を含み得る。幅だけを無条件に緩めず、静止時の10.65〜10.69 m/s²、実際の中断値、傾き・角速度、受けの接触を併せて評価する。受けを抜いた自立や歩行は、脚が荷重を受けることを先に実証してから判定する。

生ログはJetsonの `/home/jetson/singularitydog-logs/fixed-catch-30s-20260929-r57/report.json` とMacの `/private/tmp/fixed-catch-r57-report.json` に保存した。公開リポジトリへ生ログは入れない。

その後、操作者が脚と箱の位置を変えたため、40V On・QDD脱力のままr58でUID・12軸角・電圧を読み直した。最低電圧は約40.1V、各軸の静止角の測定幅は0.014°以下だった。全12軸とも保存校正を使うとモデル範囲内で角度枝は一意だが、r57の開始角との差は最大約16.2°で、r57の±0.5°開始条件は無効になった。40Vはr58記録後にOffになったため、r58も次の実出力用の電源世代記録ではない。旧設定の上限だけを緩めて再実行しない。

[オフライン計算ツール](../tools/plan_supported_preload.py)で、r58姿勢と固定D17モデルから0.5／1／2mm相当の脚伸展を比較した。0.5mm案は最大関節差約1.60°、静止時の推定PDトルク約0.34Nmで現行0.5Nm監視上限内。1mm案は右前ID1が約3.38°・約0.71Nmとなり、旧±3°経路と現行監視上限の両方を超える。モデル座標上の4足先には最大約44.8mmの高さ差、他の3足を通る平面から左後足まで約8.33mmの距離がある。後のIMU記録は機体の前後・左右の傾きを示し、この高さ差の大半は傾きでも説明できるため、モデル座標の高さ差だけで非接地とは判定しない。床の荷重・接地は別途現物で確かめる。計算結果は`motor_output_allowed: false`、現姿勢の開始範囲・電源世代・機械的な経路は未承認と記録する。

40V Off・高い箱を残した状態で4足先に薄い紙を差し込むと、操作者の確認では**4足とも紙が挟まらなかった**。足先が床に見えても、少なくともこの姿勢で足先に荷重が掛かっている証拠はない。脚が弱いと結論する前に接地・原点・姿勢の食い違いを解消する。0.5mm案の実出力は、新姿勢に結び付けた設定・経路と受けを確認し、箱を残したまま短時間に限定する。r57のIMU停止は箱を抜く操作中に起きたため、加速度範囲を無条件に緩めて再試行する根拠にはならない。

[RobStrideのRS05公称値](https://github.com/RobStride/Product_Information/)は定格1.8 Nm（100 rpm時）、ピーク5.5 Nmだが、定格値には資料指定の放熱条件が付く。これは組立後のリンク・固定具・電源配線の許容値ではない。まず現行の推定PD 0.5 Nm／実測1.0 Nm監視の内側で接地と追従を測り、そこで監視上限に当たった軸だけ、仕様・温度・現物の変形を確認して変更する。
