# 箱を残す数 mm の胴体上昇：無出力の有限軌道候補

4脚それぞれを横から確認したL字のType17原記録と、最後に全脚を床へ戻した12軸記録が同一起動・同一UID・全軸無効／電流0で揃った。原記録はJetsonの `RO-fr-camera-L-20260927.json`、`RO-fl-camera-L-20260927.json`、`RO-rr-camera-L-20260927.json`、`RO-rl-camera-L-20260927.json`、`RO-box-pose-after-all-camera-L-20260927.json` にある。私有の生角・UIDはこの文書へ転記しない。これらはL姿勢と床姿勢の**読取り**であり、全12軸の回転符号、L姿勢の正確な関節角、足裏荷重、立位中の掃引離隔を実証しない。

[無出力候補生成器](../tools/offline_box_rise_candidate.py)は、同じ起動と12 UIDに結び付いた4件のカメラL、床に4足がある新鮮な12軸姿勢、支持姿勢の±0.5°内の開始位置、全軸の実測生角範囲、脚ごとの非足先部品の実測離隔を要求する。固定付け根モードではID3/6/9/12の生角を全101点で完全に固定し、動かす足先側・上脚8軸だけの符号とL実角を要求する。2関節の平面逆運動学で公称2 mmを4秒かけて上げ、4秒で元の箱上姿勢へ戻す。付け根の実角の絶対値が17°以内なら、横方向の足球移動の計算上限は約0.61 mm。これは現物の滑りや接地力の保証ではない。各点で動かす関節のD17限界から2°以上離し、角度の折返しを禁止する。離隔の測定不確かさは2 mm以下、実測離隔はモデルの最大掃引移動量＋不確かさ＋5 mm以上を要する。モーター筐体、配線、足先や支持箱の実際の掃引は計算だけでは証明されない。従来の12軸3次元モードも残すが、付け根を動かすため初回試行には使わない。

**現物記録だけでは候補生成を拒否する。** 動かす8軸のL実角の精度と全掃引離隔・生角範囲の実測レビューが未完成である。現在の歴史的符号を仮置きしてID10だけ反転した3次元FKでは4番目の足中心が他の3点の平面から約4 mm離れる。固定付け根モードはこの推定平面を軌道計算に使わず、床接地の現物証拠を別に要求する。IMUの静止重力方向とFKのピッチ／ロールは概ね1°以内で近いが、IMUは未校正で加速度ノルムにも約8.8%の偏差があり、数 mmの接地・上昇の検証にはならない。

専用の[2 mm試行ランナー](../runtime/singularitydog_hw/rs05_box_rise_trial.py)と[候補検証](../runtime/singularitydog_hw/box_rise_candidate.py)を追加した。固定付け根101点の全12軸生角を両USB2CANへ80 msごとに送り、元の箱上姿勢でさらに20周期保持して全12軸STOPを試みる構造である。各周期に両バス各1軸の電圧・watchdogを読み、全軸の返信鮮度、位置追従、速度、故障、返信トルク、送信フレーム、周期期限を監視する。`LIVE_OUTPUT_ENABLED = False`、実機ランチャーなしであり、候補生成器も `motor_output_allowed: false` を返す。既存の[`rs05_load_transfer_hold.py`](../runtime/singularitydog_hw/rs05_load_transfer_hold.py)と[`rs05_fixed_stance_trial.py`](../runtime/singularitydog_hw/rs05_fixed_stance_trial.py)の許可ゲートは変更していない。

合成姿勢の[テスト](../tools/test_offline_box_rise_candidate.py)では、足先の水平位置を保つ上昇・下降、終点の元姿勢への復帰、符号／原点の欠落、支持開始姿勢の不一致、関節限界、過大な離隔仮定、起動・UID・カメラ参照の不一致を検査した。実機の角度精度・荷重・干渉はこのテストの対象外である。

[仮想バス試験](../runtime/tests/test_rs05_box_rise_trial.py)は、閉じたソースゲート、正常な上昇・帰還・全12 STOP、故障・欠測・返信遅延・周期超過・書込み失敗・電圧低下・watchdog変更・追従外れ・送信フレーム不一致・STOP未確認を検査した。これはKp3の力不足、実機バスでの80 ms期限、足裏摩擦、支持箱への復帰、配線や固定具の干渉を立証しない。候補・4カメラL・床記録・角度審査・物理審査・URDF・ランナー／検証器の各SHAを束ねる非公開パッケージと、無効化実機プリフライト、全掃引の現物確認はまだない。

直近の12軸無負荷電圧の最低値は37.02 Vで、現行35 V遮断閾値から約2 Vしかない。荷重時の電圧降下が未測定なので、有効化試験の前に充電または電源交換を済ませ、同じ現物条件で再測定する。

質量8.14 kgを4足へ均等に分けても鉛直床反力は約20 N/足。現在姿勢を使った静力学候補ではFR/FL足先側に約1.20/1.30 Nm、FR付け根に約1.28 Nmを要し、RS05の約1.2 Nm静止定格付近または超過する。荷重の偏りで増える。Kp3で2〜4°の位置偏差から得られる候補トルクは約0.1〜0.2 Nmに過ぎず、このランナーのKp3設定で持ち上がるとは見込めない。ゲインまたはフィードフォワード、連続トルク・時間、冷却、荷重配分を別に審査するまでソースゲートを開かない。
