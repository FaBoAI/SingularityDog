## HW-ID11-POS-001：左後脚中央 RS05 の位置値飛び

記録日：2026-09-20。更新：2026-09-21。状態：**交換済み・別個体の認識と手動5姿勢の再記録完了、制御用校正は未検証**。

2026-09-20のユーザー方針は「ID 11の値とびは、記録して、問題発生時に交換」。2026-09-21の手動校正後に交換を決定し、続いて「11交換しました」と報告された。読み取りでID11だけ個体UIDが変わったことを確認した。故障原因確定・校正完了とは扱わない。

### 確認できた事実

- 対象はユーザー申告の CAN ID 11、左後脚の中央関節、RobStride RS05。
- HW-036 では位置値が約332.326°と378.789°の間で切り替わった。HW-046にも約46°の一時的な変化がある。
- 左後脚のL字姿勢を記録したHW-046/047では、位置中央値に約43.271°の差が出た。ユーザーは「ほぼ同じL字を保持していた」と回答。
- 生の受信フレームにも値の変化があり、送信元ID・位置レジスタ・データ型の照合と再解読は一致。変換処理の取り違えやタイムアウトは確認されていない。原因とモーター故障は未確定。
- 続くHW-048は12.2秒・各関節60点の読み取り。ID11の位置幅は0.0227°で、大きな飛びは再現しなかった。異常解消を証明するものではない。

[メーカー仕様](https://github.com/RobStride/Product_Information/blob/main/README.md)の減速比7.75:1から、入力軸1回転に相当する出力角は360/7.75 ≈ 46.4516°。過去の飛びに近い数値だが、これは原因調査の手掛かりにとどめる。46.45°の自動加減算や外れ値除去で校正値へ取り込まない。

### 交換と再確認の扱い

1. ID11を既知問題として残し、値飛び・姿勢ずれ・異常な動作が出た時点のログと状況を保存する。
2. 制御中に位置値の整合が崩れた場合は、その値を追って動かさず試験を停止して現物を確認する。これは今後の運用要件であり、専用の値飛び検出機能を実装済みという意味ではない。
3. ユーザーがID11を交換済み。旧個体は問題履歴とともに区別して保管する。交換後の確認は読み取りだけで行っている。
4. 交換後はIDと部位の対応、回転方向、原点、可動範囲を再確認し、旧個体の補正値を流用しない。

## HW-RS05-VEL-001：位置が安定した状態での速度値の揺らぎ

2026-09-21、ID3のType2速度−0.07248rad/sが旧静止閾値0.05rad/sを超え、右前脚試験を有効化前に中止。
終了時は全3軸の新しい停止状態0・故障0を確認した。試験前後の位置中央値差は全12軸で最大約0.0057°。

続く停止状態のType2記録では、各30点・約3秒で位置幅は0〜0.022°、速度最大絶対値は約0.091〜0.092rad/s。
別のType17読み取りでも、固定10秒を2回、各軸各50点を記録した。
各区間の位置幅は約0.014〜0.017°、電流0Aだが、速度最大絶対値は0.079〜0.188rad/s、
速度RMSは0.036〜0.053rad/sだった。識別3件・読取1,200件の生受信を再解析し、全フレームが記録と一致した。

RS05マニュアルのType2速度範囲±50rad/sと現行変換式は一致している。
速度量子化幅約0.001526rad/sだけでは、今回の揺らぎの大きさを説明できない。
速度推定のノイズや小さな振動などの区別は未確定。速度値をゼロへ書き換えたり、ギア比や符号を推測で変更したりしない。
静止判定として固定時間窓の位置幅・位置傾き・速度RMSを併用する仕様を実装し、関連39テストを通過した。
これは旧単点判定と意味が異なり、同等の安全性が証明されたという扱いにはしない。

13:36の固定2秒・21点の実機確認では、ID1速度RMSが0.05044rad/sとなり、上限0.05rad/sを超えた。
位置幅はID1・2が0、ID3が約0.022°だったが、判定は不成立のまま保存し有効化前に中止した。
全3軸の停止状態0・故障0を確認済み。判定を通すための取り直し・閾値調整は行っていない。
[判定仕様](rs05-supported-leg-stationarity.md)と[実機準備状況](hardware-readiness-20260921.md)を参照。

その後、保存した手動変位と角度・速度の整合を確認し、支持台上の右前脚相対試験専用のposition-v2を追加した。位置幅・傾き・末尾窓・速度平均を検査し、速度RMS超過は警告として保存する。関連47テストをMac・Jetsonで通過後、3回の限定駆動と停止を確認した。旧判定の不成立はそのまま保持し、他脚や全脚制御へ拡大していない。速度揺らぎの原因と、微小運動・標本間振動の検出限界は残る。
