# L17・第22回：挨拶動作は2周期達成、位置と方位の保持は未達

**大きい振り幅のlarge条件は、左前足を2往復振り、四足へ戻って2秒保持する動作を2周期とも達成した。** 総合判定は未達。最大方位ずれ5.827°と最大平面位置ずれ7.757cmが、それぞれ5°・5cmの基準を超えた。最後の位置ずれは2.888cmまで戻るため、終端だけで合格とはしない。

同じ親モデルからsmall・medium・largeを**それぞれ500更新**し、各 `model_499.pt` を評価した。計1500更新は3モデルの合計で、1モデルを1500更新した結果ではない。3条件と追加評価は同じ第22回に含め、開発系列は22回となる。

各片道は20mm以上、反転確認には2mmの幅と250ms以上の移動時間を使う。同じ実測端点で、胴体相対Xと初期方位に固定したworld Xの両方を満たす必要がある。胴体だけの移動や細かな揺れを手振り成功には数えない。

## 残った課題

**largeの位置ずれ最大は24.900秒、足を下ろして戻す段階。** 予定した支持移動3.5cmに対して実際の最大ずれは7.757cmだった。方位は手振り中に約1.327°以内を保つ一方、1周期目の足下ろし開始+0.584°から終了−4.990°へ回り、保持後−5.727°まで進む。最後は−5.827°となった。復帰と保持が重点的な修正箇所である。

**mediumの2秒不足は、四足保持に入った直後の左後足の支持不足。** 1周期目は6サンプル＝15ms、2周期目は8サンプル＝20ms、垂直接触力が1N以下になった。高さ・傾きが原因で失格になった標本はない。1.985秒・1.980秒を2秒に丸めず、未達として残した。方位は基準内だが、最大XYずれ7.112cmも課題となる。

**smallは前足を浮かせているが、必要な往復距離が不足。** 予定1秒窓で補助的に測った胴体相対の振れ幅は概ね17.7〜19.8mmだった。4秒全体の最大最小差が約20.1mmあっても、20mm以上の2往復が成立したことにはならない。

成立した片道のworld X距離の最小値はmedium 20.0023mm、large 20.6482mm。mediumは境界に極めて近い。位置保持を改善しながら、往復距離の余裕も確認する必要がある。

## 学習と追加評価の来歴

物理モデルは第21回のD16を維持し、課題を伏せ・ジャンプから左前足の挨拶へ変更した。actor89入力・critic122入力。親の最初の87入力列を継承したが、5つのphaseとその進行度は挨拶用の意味に変わる。元の末尾2つの技能入力は廃止し、予定された前足の移動量・挙上量を表す2入力に対応する重みをゼロ初期化した。真の位置・接触力はactorへ追加していない。

3条件ともcritic、探索、optimizerと更新回数を新しく初期化し、本学習500更新・4,096,000遷移を完了した。optimizerの17状態は各10,000 step。各条件の使い捨て2更新の動作検査を本学習へ引き継いでいない。本学習は2026-09-11の07:14、08:01、08:49 JSTに順次終了し、追加評価を含む全体は09:00 JSTに完了した。

largeを選び、追加学習なしでseed43・44も28秒評価した。**seed42・43・44の400Hz計測配列はバイト列まで完全同一。** 数値・判定は同じで、映像ファイルのSHAだけは異なる。同じ条件の決定的な再現性確認であり、異なる初期姿勢や外乱に対する独立した頑健性試験3回とは扱わない。

## 次回の候補（L18・第23回、未開始）

largeの振幅・挙上を維持して、支持移行・足下ろし・四足保持の方位とXYを重点修正する案を考えている。左後足を含めた四足への荷重回復を促し、保持に入る前の短い整定余裕を比較する。必要な2秒保持や5°・5cmの基準は維持し、各500更新で変更因子を絞る。

次の評価では、初期方位・姿勢、外乱、明示したセンサ誤差などの実際の条件差も検証したい。残差制御の偏りや支持移行の追従誤差は原因候補だが、まだ特定していない。今回の結果整理で次の学習やCAD修正を実施したわけではない。

選択した数値と出所のSHAは[評価JSON](../evidence/l17-evaluation.json)に収録した。元の400Hz記録を照合し、凍結評価関数のローカル再計算は全項目が許容1e−12以内で一致。別のphase別集計で未達箇所も確認したが、別実装の合否アルゴリズムによる二重検証ではない。公開物は完全な再現パッケージではなく、実機の動作・強度・耐久性を保証しない。
