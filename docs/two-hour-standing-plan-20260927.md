# 2時間で進める実機起立準備（2026-09-27）

目標は学習済みモデルによる四足自立だが、現在は**1人在席、独立した落下受けなし、40 V On、胴体は箱上、4足接地**である。モーターは停止・脱力しており、読取り専用の確認を進める。この条件で通電中に箱を抜く試験は行わない。箱上の現在角2秒保持と全12軸STOPは既に成功しているため、同条件の保持を繰り返して自立と判定しない。試験終了時のSTOP・通信断・40 V遮断では脚が脱力し得る。

同日追加の無出力計測では、前後2バスの12軸Type17位置・速度取得20周期の最古要求から最後の返信まで中央値17.95 ms、最大21.90 ms。IMU・推論・送信を含まないため、20 ms全工程は未達判定のまま。続く12軸Type2 STOP返信＋IMUの並列取得は11.90 ms、入力組立は3.83 msだったが、旧L字校正を現在の箱上姿勢に当てるとID1/3/6/9/12が学習モデルの関節範囲を外れ、**推論前に停止**した。Type17とType2の角度差は12軸すべて0.03°以内。ID1/3/9には旧基準との大きな角度枝差があり、値を自動で±360°補正して駆動しない。非公開ログはJetsonの `RO-dual-can-20260927-fast-r1` と `postfw-integrated-20260927-fast-r1` に保存した。

ID10の手動二姿勢比較では、操作者が実物の出力部も約90°動いたと確認し、Type17生角は下向き移動で−92.04°だった。他の左後2軸は各0.2°以内で、旧ID10符号候補の再検討が必要。手を離して新しい箱上・4足接地姿勢へ戻した後の20周期では全軸の位置幅は最大0.020°、取得中央値17.98 ms、最大20.11 msだった。元のA姿勢と角度が異なるため、次に実機で使う始点は必ずこの新姿勢から取り直す。ID10の旧符号を自動反転したり、未検証の候補を学習済みモデルの実目標送信に使ったりしない。

**箱を外す試験への追加条件:** 胴体全重量を受け止める担当者と、支持台操作・即時40 V遮断を切れ目なく担当できる人員、または全重量と短い落下を受けられる固定補助具が必要。40 V Offで取り外し・復帰を再演し、4足接地・通電時の立位姿勢・荷重下の追従と電圧・温度・故障を確認してから、部分荷重、短い手離しを別試験で行う。人手も補助具もない今日の2時間で、支持台なしの学習済みモデル起立は達成判定できない。

現行の箱上2秒ランナーは開始角を繰り返し保持するだけで、胴体を持ち上げる指令や箱を抜く窓を持たない。モデル起立には、実機の角度変換と、**実目標送信を含む連続20 ms制御**も別途必要である。箱上保持の最長周期65.61 msを50 Hz方策の合格証拠に使わない。

**今回の進捗判定:** 現起動の個体照合と二バス読取りは完了。ID10の出力角は現物と一致する一方、旧符号候補が現物の下向き回転と食い違う。旧校正では実入力が範囲外となり推論へ進まない。したがって次の工数は校正・脚先幾何の再照合が中心で、ここを終える前にモデルの実目標送信や箱の取り外しへ進まない。人員または独立落下受けが今日中に確保できなければ、2時間内の自立合格は判定できない。
