# 10月6日：脚の調整後の無出力推論と20ms再計測

脚を動かした後、操作者が手離し・静止・40V On・箱支持を確認した。現姿勢を読み直し、保存済みの原点・符号と整数回転の候補から、全12軸についてモデル範囲内の角度候補を一意に選べた。原点を書き換えたり、範囲外の値をクリップしたりしていない。これは数値的な照合で、原点の絶対精度の確定ではない。

## 性能設定を揃えた501周期比較

同じ姿勢・角度候補・gyro候補・高速C++モデル、0.9ms送信間隔で、取得→実推論→12軸STOP代理返信→後処理を測った。加速度はrawのままで、今回の新しい補正候補はまだこの実機経路へ入れていない。有効化と学習目標の送信はゼロ。

| 指標 | 通常の性能設定 | 計測中だけ性能設定を適用 |
|---|---:|---:|
| 周期数 | 501 | 501 |
| 取得の中央値 | 7.989281ms | 7.616694ms |
| 推論の中央値 | 5.669440ms | 2.629898ms |
| 全工程の中央値 | 24.007077ms | 18.941301ms |
| 全工程の最大 | 25.165893ms | 19.906224ms |
| 全工程20ms超過 | 501 | 0 |
| 返信欠落 | 0 | 0 |

Super ModeだけではCPUの最低周波数を固定しない。比較では既存の `jetson_latency_power_scope.py --diagnostic --with-cpu-performance` を使い、CPU最低周波数1.728GHz、C7無効、EMC最低周波数3.199GHzを計測中だけ適用した。呼出しはnice −10を指定。複数の設定をまとめて変えた比較であり、CPU・メモリ・待機・優先度それぞれの寄与は分離していない。

性能設定側は初回を含め501周期すべて20ms以内。厳密な開始間隔は最大20.006450msで20msをわずかに超え、元の値を記録に残す。これは[合意済みの開始時刻の扱い](accepted-angle-timing-policy-20260928.md)に沿って処理期限とは別に扱う。今回の成功を長時間・実送信・補正後の全制御の保証へ広げない。

各runで取得時・最後の代理出力の両方に、12軸×501周期のSTOP応答を元bytesから独立照合した。返信はすべてmode0・fault0。原本の `stop_confirmed` はnullのままで、物理的な停止検出値へ変更していない。操作者は両比較と次の読取りの間、触れていない・電源操作なし・現物異常なしと回答した。

終了時の性能scope復元記録に加え、後からsysfsを読み、両CPU policyの最低729.6MHz、全6CPUのC7有効、EMC最低204MHzへ戻ったことを確認した。

## IMU補正を同じ保存入力で比較するツール

[2系統CANとIMUの読取り](../tools/capture_dual_policy_replay.py)と、[補正前後のモデル比較](../tools/compare_imu_candidate_policy_replay.py)を追加した。前者は既定ではPLANだけ、明示実行時もCANは識別とパラメータ読取りに限定する。後者はファイルだけを読み、実機を開かない。元の時刻とraw通信を保持し、補正計算用のデータを推論比較で再fitしない。

約10秒で12軸の5項目を45巡、IMU957点、CAN要求・返信2,752組を取得した。最後の途中4要求も削除せず、`COMPLETE_WITH_WARNINGS`、errorsなしとして保持。IMU設定の復元を確認した。取得済みソースの途中区間に関する説明2文を後から訂正したが、取得ロジックと原本は変更していない。

この比較用収録は元の通信との照合を優先した逐次CAN読取りで、先頭の軸は推論時点から約206ms前になる。100msの鮮度条件では4条件とも最初の計算前に止まった。失敗記録を残し、**ファイル解析専用の500ms条件**で同じ記録を比較した。実機の100ms監視値や20ms周期を緩めたものではない。

raw／補正後とh=0／h=1の4条件で、モデルと内部状態をそれぞれ独立に初期化し、各400回の推論を完走した。変えたモデル入力は重力方向3成分だけ。位置・速度・gyro・指令・h、元時刻、関節順を保持している。補正による目標角の差はh=0で最大1.414568°、h=1で最大1.652274°、いずれも右後脚の膝ID7だった。目標の有効範囲検査も通った。

**現在姿勢から100%のモデル目標までの差は最大46.173424°（ID7）。** 補正による約1.65°の差とは別の量である。範囲内であることは、現在の脚からそこまで安全に動かせることや、自重を支えられることの証明ではない。800組の補正前後ペアを独立式でも照合し、重力方向のfloat32値と他5入力の保持が一致した。比較に使った入力の最大年齢は229.187msで、実機の入力鮮度の合格にはしない。

新しい通常姿勢のIMU973点でも、固定した補正候補を後方適用した加速度ノルムの平均ずれは+8.6786%から+0.05851%へ減った。これは[6方向の補正候補](imu-six-face-results-20261006.md)を別の記録に適用した評価で、機体姿勢の絶対精度とは分ける。

後の同時収録957点でもraw換算・設定・trim・復元を独立照合した。この収録は平均約26.389°Cで、計算用記録の約29.001°Cより低い。固定補正後の平均ノルム偏差は+0.20962%。温度による影響の分離や温度補償まで検証したことにはしない。
