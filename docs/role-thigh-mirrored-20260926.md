# 上脚4軸の鏡像方向試験と前脚の干渉 — 2026-09-26

[今回の実測値・ログSHA-256](../evidence/role-thigh-mirrored-20260926.json)

Jetson の I2S スピーカーで「テスト開始します」を再生してから、支持台上で全12軸を5秒保持した。前後両バスが100周期を完走し、全12軸のSTOPを確認。操作者も音声を聞き取り、現物の異常はなかった。これは声を伴う実機試験の開始条件を満たす。

続いて、現在位置から上脚 ID 2/5/8/11 を**犬の後ろ側へ同時に**最大10°動かす診断を行った。右側 ID 2/8 は生角度+、左側 ID 5/11 は生角度−とした。8秒ランプ＋1秒終点保持、他8軸は現在位置保持。学習済みモデルの指令や起立目標は送っていない。

最初の音声ゲート付きパッケージ r10 は、モジュール読込み監査で駆動前に止まった（motor-enable送信なし）。読込み順を修正した r11 で、音声再生の後にこの診断を実施した。

| 上脚 | 指令の生角度 | 実移動 | 返信トルク最大絶対値 |
|---|---:|---:|---:|
| 右前 ID2 | +10° | +3.28° | 1.531 N·m |
| 左前 ID5 | −10° | −3.50° | 1.485 N·m |
| 右後 ID8 | +10° | +9.43° | 0.154 N·m |
| 左後 ID11 | −10° | −9.63° | 0.126 N·m |

前後各180周期の指令と終点観測まで行い、ID2 の終点差6.73°で `ABORTED`。**全12軸のSTOP返信、両ポートの閉鎖、ロック解放を確認した。** 操作者は、後脚は正常に動き、前脚2本は自分のカーボンポールに当たって途中から動けなくなったと確認した。CANの故障ビットは4本とも0。前脚の高い返信トルクと追従不足は、この物理干渉で説明できる。

この後ろ向き経路ではゲインやトルク監視値を上げて再試行しない。別経路として、[前脚を顔側へ動かす10°試験](front-thigh-faceward-20260926.md)を同じbootで実施し、接触なく完走した。後脚の10°成功と前脚の顔側10°成功は、12軸の起立・歩行や学習済みモデルのDeploy成功を意味しない。
