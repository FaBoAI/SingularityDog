# 実機検証の結果と残件 — 2026-09-25〜26

## 9月25日

RS05の12軸すべてを公式FW `0.5.0.13` へ更新した。更新後に全軸のUID・版数・STOP返信（mode 0／fault 0）を照合し、最後の電流読取りは全軸0 Aだった。更新作業中はモーター有効化と動作目標の送信を行っていない。更新後も6軸の自動報告開始は安定せず、失敗後の解除とSTOPは再検証した。

実入力取得・入力組立て・実推論・STOP代理送信の無出力診断を改善した。最古入力の取得開始から最後のホストwrite復帰まで、3回の中央値は `20.063 ms`、最大 `20.136 ms`、最良の1回は `19.785 ms` だった。最後の返信までの中央値は `22.791 ms`。送ったのは学習済み目標角ではなくSTOPで、連続50 Hz制御や全周期20 ms以内は未達である。

## 9月26日

MAX98357Aを使うI2S2音声案内を実機スピーカーで確認し、「テスト開始します」を明瞭に聞き取れた。音声再生に失敗すると音声付き試験を起動しない構成とした。

起動ID `1743e35c-3b44-4fa6-88a9-855b5b62e214` で12軸の無動作記録を取り直した。最初の記録はSTOP順序が保持パッケージの監査条件に合わず、全軸STOP先行で再取得した記録を使用した。無効化の保持プリフライトと前脚付け根10°プリフライトは、ともにモーター有効化・動作用ゲインなしで完了した。[現起動の記録](stance-current-verification-1743-20260926.md)にログとハッシュをまとめた。

有効化した12軸の現在位置保持は前後各100周期を完走し、全12軸STOP、ポート閉鎖、ロック解放を確認した。操作者から実機の異常は報告されていない。続く右前付け根ID3を+10°、左前付け根ID6を−10°へ向ける試験は、最初の周期中に `Stale feedback` で中断した。パケットゲートは前後各4/6軸の最初の動作用送信と完了周期0を記録し、全12軸STOPを確認した。操作者は動き・異常・接触を見ていない。**10°軌道は未完了**である。

Enable後のゼロゲインパケットを扱うゲートと、最初の動作周期だけ返信鮮度の許容を125 ms（通常周期は100 msのまま）とする修正をローカルで検証した。`runtime/tests` の全1195件を実行し、1件スキップ、失敗0件だった。後者は実機では再試験していない。次の判定には同一起動の根拠を確認した上で10°軌道を完走し、追従と実物の隙間を観察する必要がある。固定立位、荷重移行、学習済みモデル出力、歩行、連続20 ms制御は確認していない。
