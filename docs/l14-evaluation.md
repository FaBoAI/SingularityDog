# L14・第19回：伏せ保持・起立を2回達成、方位と位置のずれが課題

ユーザー指定の `model_500.pt` を、同じL14形状・駆動条件で24秒評価した。伏せ2秒保持と、起立後の四足支持2秒保持をそれぞれ2回達成し、登録済みの標本単位基準をすべて通過した。一方で、向きは+47.0648°変化し、位置は11.4919 cmずれた。方位・位置維持は今回の合否基準に含まれていない。

元の1000更新計画は、2026-09-10 18:28:19 JSTにユーザー指示で停止した。停止直前の最終ログはiteration 613で、少なくとも614更新が完了している。保存された進捗集計で直接確認できるのは600更新時点。今回選択した `model_500.pt` は0始まりのiteration 500、つまり**501更新後**のモデルであり、停止時点の最新モデルや1000更新完了結果ではない。独立評価のための追加学習は0回。

伏せ時は基準高さ95 mmから±20 mm以内、起立時は基準高さ255.5665 mmから±25 mm以内も全保持標本で満たした。2秒は400 Hzの連続800標本の時間幅として数え、799標本を2秒として扱わない。

全24秒で禁止接触は0標本・最大0 N、実関節速度超過は0標本。最大実関節速度は5.9431 rad/s（設定上限10）、最大駆動トルクは4.3086 Nm（設定上限5.5）だった。接触力は部位ごとの合力で、相手が床か別部品かを個別に特定するものではない。

## 変更した設計と学習

前回L13の物理モデルをもとに、腹部を床で支持する丸みのあるPLAスキッドと固定部を追加した。追加質量は155.027 g、全質量は7.786162 kg。元の17リンク・16ジョイントは保ち、固定子リンク1つと38個の衝突形状を追加して、合計628衝突形状とした。CADの9個の参照姿勢を検査し、既存形状との追加干渉なしを確認した。これは有限個の参照姿勢の検査であり、学習後の全動作・印刷強度の検証ではない。

滑らかな関節参照軌道に、PPOで学習した補正を加える構成。actor入力は87、学習用critic入力は118、出力は12関節の補正で、歩行モデルの重みから新モーションへ継ぎ足したものではない。actorの姿勢入力には理想的なIMU融合を仮定し、実機のノイズ・漂流は未検証。256環境・1更新32 stepで学習し、評価対象501更新に対応する遷移数は4,104,192。optimizerは17状態それぞれ10,020 stepで、モデルの数値が有限であることを確認した。

初回起動は未学習チェックポイントの保存処理で失敗し、学習更新は0回だった。保存処理を修正した後、使い捨ての2更新の動作確認を通過し、本学習を新規初期化して開始した。この2更新は評価対象モデルへ引き継いでいない。未学習の同条件参照動作は3.92秒で禁止接触により停止しており、今回の24秒完走と分けて記録する。

## 残る課題と次の方針

- **方位・位置維持**：最初の物理標本から終端までにyawが+47.0648°、平面位置が11.4919 cm変化した。伏せと起立をその場で繰り返す改善が必要。
- **連続動作の駆動負荷**：負荷モデルの指標 `h` は最大約1.0の上限に達した。2周期間で値をリセットしておらず、保持成功と負荷の余裕は別の課題。`h` は実測温度ではない。
- **学習中の失敗**：600更新時点の集計では終了4668エピソード、速度最大10.26435 rad/s、超過1標本を記録した。今回の評価で接触・速度超過が0だったことから、学習全期間も0だったとは扱わない。
- **確認範囲**：単一seed・1試行・平坦床の標本評価。複数条件での再現性、実機のIMU、PLA部品の強度、長時間の運転は未検証。ジャンプ・後ろ足2本立ちの学習はまだ実施していない。

ユーザー指定により、**当面の新規学習は500更新**を基本とする。新規初期化から厳密に500更新なら最終iterationは499になる。今回の501更新という履歴は訂正せず保持し、元の1000更新計画や凍結済み条件を後から書き換えない。停止済み学習は再開していない。
