# 公開範囲

公開するのは、このプロジェクトの検討経緯、一般化した自作の検証手順、新規記述した補助ツール、自分たちの実験結果の選択した数値です。

README の進捗動画は、選択した自作実験の移動位置・向き・足上げを図として新規描画したものです。メーカーの外観・CAD・メッシュを使わず、元のシミュレーション録画の編集物でもありません。「実測ログの可視化」と常時表示します。全600サンプル・50fpsのMP4と、同じ12秒を保つ縮小GIF、静止画だけを個別のSHAで登録しています。

メーカー固有の図面、寸法・仕様表、CAD・メッシュ、部品内部構造、マニュアル、第三者コード・モデル・画像・動画・重みを同梱しません。参照元リポジトリを複製したり、名前だけ置換して公開したりもしません。接続先、利用者のホームディレクトリ、認証情報、クラウド文書 ID、実行環境の生ログも対象外です。

既存の私的な作業フォルダを丸ごとコピーせず、このリポジトリ専用に文章とツールを記述しました。`evidence/progress.json` は自作実験レポートから明示的に選んだ測定値だけです。内部ファイルの SHA-256 は追跡の手掛かりですが、元ファイルは同梱していないため、この公開パッケージだけで元実験全体を再現・検証できるという意味ではありません。

更新時は `RELEASE_FILES.json` の明示リストを確認し、`tools/check_publication.py` で機械的な漏れを検査します。検査は文字列・ファイル形式の確認であり、文章やコードの出自は別途レビューします。新しい第三者素材を許可リストに追加して公開する運用は行いません。

動画の例外は `evidence/media-publication.json` で、実測データ・描画スクリプト・個別の出力ファイルのSHAを固定しています。任意の動画や画像を一括で許可する仕組みではありません。内部ログ、メーカー由来の形状を映した既存録画、ローカル比較画面の動画は引き続き公開対象外です。

工具やシミュレータの名称はワークフローの説明に必要な範囲で参照できますが、それらのコードや製品データをこのパッケージの独自成果と扱いません。
