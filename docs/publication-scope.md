# 公開範囲

公開するのは、このプロジェクトの検討経緯、一般化した自作の検証手順、新規記述した補助ツール、自分たちの実験結果の選択した数値と、個別に指定された進捗メディアです。

## 個別に指定された画像と録画

2026-09-09にユーザーが履歴への掲載を指定したCAD画像1点とシミュレータ録画5本を、元ファイルと同じバイト列で収録しています。それぞれ既存のプロジェクト成果物とSHAが一致しました。CAD画像は設計イメージ、録画はシミュレーションの経過で、完成実機や歩行合格の証拠とは扱いません。画像に映る部品・製品の権利を、このリポジトリの独自成果として主張しません。

README用のGIFは、その5本の全区間を等速で縮小したプレビューです。元の映像を切り抜いたり、成功部分だけを選んだり、補間・速度変更をしたりしません。各元ファイルとGIFは `evidence/recording-publication.json` にSHA・サイズ・変換元を個別登録しています。その後、L05とL06の結果動画のGitHub掲載もそれぞれ明示指定されたため、検証済みの4方向・12秒モンタージュと全区間GIFを個別に追加しました。新しい動画もSHA・サイズ・変換元を固定しています。他の録画や第三者の素材を一括公開する許可ではありません。

## 実測チャート

従来の `forward-history` は、選択した実験の移動位置・向き・足上げを図として新規描画したものです。メーカーの外観・CAD・メッシュを使わず、元のシミュレーション録画の編集物でもありません。全600サンプル・50fpsのMP4と、同じ12秒を保つ縮小GIF、静止画を `evidence/media-publication.json` に個別登録し、入力と描画スクリプトのSHAも固定しています。

## 含めない情報と検査

編集可能なCAD・メッシュ・モデルファイル、メーカー固有の図面・寸法表・仕様表・マニュアル、第三者コード、学習済み重みを同梱しません。接続先、利用者のホームディレクトリ、認証情報、クラウド文書ID、実行環境の生ログも対象外です。既存の私的な作業フォルダを丸ごとコピーせず、公開対象だけを選んでいます。

内部ファイルのSHAは追跡の手掛かりですが、この公開パッケージだけで元実験全体を再現・検証できるという意味ではありません。ツールや製品の名称・画面上の描写は、その実装や製品データを独自成果として公開することと区別します。

更新時は `RELEASE_FILES.json` の明示リストと個別メディア台帳を照合し、`tools/check_publication.py` で文字列・形式・SHAを検査します。今回の録画は全フレームをデコードし、時間順の静止画とメタデータを確認しました。文字列検査だけで画面内容や出自を判定したとは扱いません。
