# 支持台上の3関節試験：起動前の静止判定

この判定は、支持台に載せて脚を浮かせ、操作者がモーター電源を切れる状態で行う3関節診断専用です。四足起立・歩行・強化学習方策の実機展開を許可する判定ではありません。

以前の「1回の速度フィードバックが絶対値0.05 rad/s以下」という条件を、位置変化・時刻・速度RMSを併用する固定窓へ変更しました。瞬間速度の上限を拡大しただけの修正ではなく、静止判定の仕様変更です。

## 固定窓

- モーターを無効状態(mode 0)に保ち、Kp=Kd=0のneutral指令に対する全3軸の応答を取得します。
- 100ms間隔で21回、最初から最後まで約2秒を観測します。全sampleを使用し、外れ値除去・選別・自動再試行は行いません。
- 各軸の21sampleが必須です。受信時刻は増加し、隣接間隔は150ms以下、最初から最後の時間は1.9〜2.3秒でなければ中止します。送信予定から50msを超える遅れでも中止します。
- 全sampleでmode 0、fault 0、有限値、試験開始時に読んだ位置からの変化0.02rad以下、瞬間速度0.5rad/s以下、受信後100ms以内、および既存の温度範囲を要求します。この基準位置はモデルの原点ではありません。
- 全sampleの位置の最大値−最小値が0.002rad以下、時刻に対する位置のOLS傾きの絶対値が0.002rad/s以下、速度RMSが0.05rad/s以下を、各軸についてすべて要求します。
- 集計・ログ出力の後と、各enable送信の待機後に、全3軸の最後の状態と鮮度を再確認します。新しい応答によって固定窓の最後のsampleが置き換わった場合や、古くなった場合は駆動を中止します。新sampleへの差し替えで継続しません。

窓全体と各軸の集計・不成立理由を`settled_window`へ保存します。窓の途中で通信や状態の検査に失敗した場合も、得られた部分記録と不足を保存し、全識別済み軸へ停止を試行します。

## 変更しない条件と限界

動的試験の5°目標、4秒ランプ＋1秒保持、Kp=3/Kd=0.15、enable後6秒の時間予算、受信鮮度、0.5rad/sの瞬間速度制限、停止処理は維持します。原点・回転方向・可動範囲の校正を補完するものではありません。

位置の全幅は、ゆっくりした移動や往復による速度の相殺を検出するために併用します。それでも許容幅以下の微小な移動や、サンプリング周期と同期した振動は検出できないことがあります。合格を「完全な静止」や実機全体の安全性の証明として扱いません。RMSが上限を超えた場合も、都合のよい区間を再取得して通過させません。

RS05の速度換算は、メーカーの`RS05User_Manual260713.pdf` §4.1.3に基づくType2のuint16 0..65535→−50..+50rad/sのままです。Type17の0x701Bは出力軸速度のfloat(rad/s)です。静止時速度の変動原因、支持台以外での性能、物理watchdog停止遅延と総トルクの上限は未検証です。

## 明示選択の position-v2（支持した右前脚の相対試験のみ）

2026-09-21 r20までの記録では、角度幅が約0.022°でも速度RMSが0.05rad/sを超える。
全3個体の手動変位に角度が追従する証拠と、停止候補／実動作の記録を照合したうえで、
別の判定仕様を追加する。従来方式が既定で、新方式を選ぶには個体UIDに結び付いた手動応答のレビュー記録を要求する。
過去の絶対角度は使わず、電源再投入後も個体照合、新規Type17位置とType2位置の一致を確認する。

新方式も固定21点・約2秒を一度だけ取得する。位置幅0.001rad以下、OLS傾き絶対値0.0005rad/s以下へ厳しくし、
最後6点（実時間0.45〜0.60秒）の位置幅0.0008rad以下・OLS傾き0.001rad/s以下も要求する。
報告速度の符号付き平均の絶対値は0.025rad/s以下。バイアスを差し引かず、RMSが0.05を超えたことは警告として残す。
瞬間速度0.5rad/s、mode/fault/温度/時刻/鮮度、動作の5°・5秒、停止処理は変更しない。

これは静止判定の仕様変更であり、従来方式と同等との主張ではない。位置固着とゼロ平均の速度揺らぎ、
標本間の振動、許容位置幅以下の微小移動をすべて検出することはできない。
支持台・脚の離隔・操作者による電源切断を前提とする右前脚の短時間試験専用で、全脚駆動や学習済み方策へ拡大しない。
