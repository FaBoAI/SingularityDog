## 量子化と20ms周期

Type1位置指令の1段は`25.14 / 65535 rad`、約0.02198°。滑らかな微小経路でも、符号・原点・360°の枝を保って整数へ変換すると送信目標に段差ができる。速度・加速度の数値は次の3種類を区別する。

- 浮動小数の経路に適用する名目速度・加速度の上限。
- 量子化された送信参照値の差分。新しい`preload_wire_reference_audit`へ別記し、実際の関節速度・加速度の測定値とはしない。
- 実機から返る速度・トルク・位置。従来の監視を継続し、今回の修正で上限を緩めない。

詳細な251点×12軸の量子化監査は、有効化前の準備中に行う。ランタイムへ保存する監査の基準は元の確認済み姿勢（`reviewed_capture`）であり、その後の実送信全バイトを監査したという表示にはしない。新しい始点での許容範囲は、各軸の最小・最大値の24点で全経路を確認できる。符号を含む変換の単調性と、全251点の列挙結果の一致をテストした。

この始点検査はMac上の参考計測で約2.5msから中央値約0.067msへ短縮。実機の20ms周期達成を示す計測ではない。詳細監査は約7.7msかかるため制御周期内には追加していない。Pythonと実際にビルドしたC++の位置エンコーダーについて、境界値と全経路の位置コードを照合した。
