# 次ループの仕様：500更新・配色・脚先素材

当面の新規学習は**500更新**を基本にします。次の機体改訂では脚のPLA部品とPLA取手を黄色、カーボン部材とベースプレートを黒とし、ディスプレイは黒背景に目を表示します。IMUの仮設置モデルは赤を維持します。

このページは次ループへ引き継ぐ仕様と検討案の記録です。**現行CADと公開済み動画には、新しい黄色・黒の配色や目の表示は未適用です。** この記録作成に伴うCAD・シミュレーション物性の変更、学習の開始・再開は行っていません。

## 学習回数と比較の基準

| 項目 | 次ループの扱い |
| --- | --- |
| 基本予算 | 新たに500回のPPO更新 |
| 保存番号 | 新規初期化から0始まりで500更新なら、最終iterationは499 |
| 継続学習の場合 | 親の累積回数と今回追加した500更新を分けて記録 |
| 結果比較 | 使用モデル、完了更新数、形状・物性・初期状態、評価条件を明示 |
| 現在の歩行基準 | L13の前進40cm/s目標と6方向評価結果を保持 |
| 現在の伏せ・起立基準 | L14の501更新モデルの24秒評価を比較用に保持 |

L13の1,000更新完了と、L14で選んだ`model_500.pt`の501更新という過去の記録は変更しません。L14では1000更新計画を途中停止しており、選択モデルの更新数と停止時の進捗を区別します。[L13評価](l13-evaluation.md)・[L14評価](l14-evaluation.md)に結果と未達を残しています。

伏せ・起立では、保持成功を維持しながら方位・位置のずれと連続動作時の負荷を減らすことが次の改善対象です。ジャンプと後ろ足2本立ちは後続の技能候補で、実施済みの学習や評価には数えません。次の実行条件と合否基準は、開始前に変更内容と対応づけて固定します。

## 印刷と脚先の素材

使用機はCreality K1です。造形可能サイズは220×220×250mmを基準とし、配置やブリムなどを含めた収まりはスライサーで確認します。[Creality公式K1仕様](https://www.creality.com/mx/support/creality-k1-3d-printer)

本体の初期検証用部品はPLAを前提とし、[79個のCAD中実換算質量](pla-parts-mass.md)を記録しました。体積×仮定密度による値で、全79個のスライサー見積と実測重量は未取得です。実際のインフィル、壁厚、積層方向、取手と脚の強度は、印刷条件を決めて確認します。

脚先の柔軟パッドは**TPU95A系を推奨候補**とします。K1の公式対応材料にTPU95Aが含まれ、材料メーカーは同系統の柔軟フィラメントについて柔軟性と耐摩耗性を案内しています。これを候補選択の根拠としますが、特定銘柄の採用、機体でのグリップ・耐久性・衝撃吸収は未確定です。[Creality K1対応材料](https://www.creality.com/support/creality-k1-3d-printer)・[Forward AM Ultrafuse TPU 95A](https://forward-am.com/material-portfolio/ultrafuse-filaments-for-fused-filaments-fabrication-fff/flexible-filaments/ultrafuse-tpu-95a/)

脚先は交換式とし、接地面をやや平坦にする形状を設計案として残します。パッドの寸法、硬さ、固定方法、印刷条件は次の設計で比較します。提案中のTPU脚先をPLA質量表へ混ぜず、材料採用後に質量と接触特性を別途記録します。今回の記録では現在の足パッドやシミュレーションの摩擦・弾性値を置き換えていません。
