# 仕様の反映状況と次回の500更新方針

当面の新規学習は**1試行500更新**を基本にします。第21回で中央モバイルバッテリー、下面セパレーター、機器固定具の改訂を学習モデルへ反映し、第22回はその形状・質量を維持して挨拶を3条件各500更新しました。

最新指定は、黄色い脚・取手、黒を基調とする胴体・底板・固定具・顔枠です。カーボン・QDD・足先球は黒、IMUは赤、顔は黒地に白い目を継続します。第21回当時の白い底板・黄色い顔枠等はその回の記録に残し、第22回の指定と混同しません。**Fusionの最終色版F3D/STEP保存と実機・PLA強度の検証は未完了**です。

**第22回の大は、前足2往復と四足復帰2秒を2周期とも達成しました。** ただし最大位置ずれ7.76cm・方位ずれ5.83°で総合未達。[第22回の結果](l17-evaluation.md)。次は大の挨拶軌道を基に、足下ろし・荷重回復・方位と位置の保持を改善する候補です。次の試行は未実施で、実行回数へ加算しません。

## 印刷と脚先の素材

使用機はCreality K1です。造形可能サイズは220×220×250mmを基準とし、配置やブリムなどを含めた収まりはスライサーで確認します。[Creality公式K1仕様](https://www.creality.com/mx/support/creality-k1-3d-printer)

本体の初期検証用部品はPLAを前提とし、[79個のCAD中実換算質量](pla-parts-mass.md)を記録しました。**79個の質量表はL13/L14時点の構成の履歴です。第21回の新しいケース・固定具を含む最新PLA総量として使用しません。** 既存の表は体積×仮定密度による値で、全79個のスライサー見積と実測重量は未取得です。実際のインフィル、壁厚、積層方向、取手と脚の強度は、印刷条件を決めて確認します。

脚先の柔軟パッドは**TPU95A系を推奨候補**とします。K1の公式対応材料にTPU95Aが含まれ、材料メーカーは同系統の柔軟フィラメントについて柔軟性と耐摩耗性を案内しています。これを候補選択の根拠としますが、特定銘柄の採用、機体でのグリップ・耐久性・衝撃吸収は未確定です。[Creality K1対応材料](https://www.creality.com/support/creality-k1-3d-printer)・[Forward AM Ultrafuse TPU 95A](https://forward-am.com/material-portfolio/ultrafuse-filaments-for-fused-filaments-fabrication-fff/flexible-filaments/ultrafuse-tpu-95a/)

脚先は交換式とし、接地面をやや平坦にする形状を設計案として残します。パッドの寸法、硬さ、固定方法、印刷条件は次の設計で比較します。提案中のTPU脚先をPLA質量表へ混ぜず、材料採用後に質量と接触特性を別途記録します。今回の記録では現在の足パッドやシミュレーションの摩擦・弾性値を置き換えていません。
