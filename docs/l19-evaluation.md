## お座りの定義と結果

参照は鼻上げ12°・後ろ腰60mm下降・前方移動7.5mmの浅い座位。前脚を伸ばし、後脚を曲げ、四足で支える。立位2秒、下降4秒、座位3秒、起立4秒、立位3秒の16秒を2周期実行した。

座位を低い水平姿勢や転倒と取り違えないため、実測の鼻上げ角、左右の膝角度、後ろ腰の下降、前後の腰高さ差、四足の支持、静止状態を同時に要求した。予定姿勢や報酬値だけでは成功にならない。

| 指標 | 結果 | 基準 |
| --- | ---: | --- |
| 座位の連続保持 | 3.000 / 3.000秒 | 各3秒枠で連続2秒以上 |
| 立位復帰の連続保持 | 3.000 / 3.000秒 | 各3秒枠で連続2秒以上 |
| 座位中の鼻上げ | 12.088〜12.575° | 12°±3° |
| 後ろ腰の下降 | 56.706〜61.000mm | 45mm以上 |
| 前後の腰高さ差 | 64.920〜67.493mm | 48.495mm以上 |
| 最大方位ずれ | 1.536° | 5°以内 |
| 最大XY移動 | 3.358cm | 5cm以内 |
| 最終方位・位置ずれ | −0.541° / 0.321cm | 最大値とは区別 |

保持条件は**新しいお座り課題の学習前に固定**した。座位と復帰それぞれ3秒の枠で、800個の連続した400Hz標本＝2秒以上を要求し、冒頭の短い整定を許す。過去の実験を後から合格に変更する規則ではなく、799標本を2秒へ丸めない。今回は4つの保持枠すべてで、全1200標本＝3秒が成立した。

座位の横傾きは5°以内、立位の傾きは10°以内を要求する。意図した鼻上げを転倒としないため、下降・座位・起立には鼻上げ−5〜25°、横傾き10°という別の上限を設ける。保持中は四足すべての垂直支持力>1N、足底の床離隔−2〜5mm、胴体速度≤0.1m/s、角速度≤0.35rad/sも必要となる。

## 学習前後と負荷

同じお座り参照での事前評価でも、座位と復帰は両周期で各3秒成立した。ただし最大方位ずれ5.695°が基準を超えた。今回500更新後は1.536°に収まり、最大XY移動も4.698cmから3.358cmになった。今回の最大値はともに1周期目の起立中に生じている。

最終評価の禁止接触と速度超過は0標本。最大関節速度3.030rad/s、最大適用トルク1.911Nm、最大h0.0803だった。hは模擬負荷予算で、温度実測ではない。

学習中は2734エピソードが終了し、禁止接触1896環境・物理サブステップを記録した。速度超過は0、最大速度5.661rad/s、最大h0.2619。探索中の集計と最終評価を分けて記録する。

## 来歴と検証範囲

物理モデルD16を維持し、第23回の親actorから先頭81入力列を継承した。課題用の5段階・進行度・予定姿勢2入力に対応する8入力列の重みはゼロ初期化し、critic、探索標準偏差、optimizer、更新回数も初期化した。予定鼻上げと予定胴体下降量をactorへ渡すが、真の位置・高さ・接触力を新たにactorへ追加していない。

新規500更新・4,096,000遷移を2026-09-11 11:34 JSTに完了し、最終評価は11:38 JSTに終了した。使い捨て2更新の動作検査は本学習へ引き継がず、評価時の追加学習もない。

評価のJSON・実測配列・動画は遠隔と手元のSHA一致を確認した。凍結した独立NumPy評価器を手元で再実行し、元集計の全206照合項目が一致した。同じ評価器の再計算であり、別実装の合否アルゴリズムによる二重検証ではない。動画は全1600フレームをデコードし、時間順の代表画面と最初・最後を確認。GIFも全フレームと表示時間を照合した。

[選択した評価値とSHA](../evidence/l19-evaluation.json)を公開する。単一seed42・平面での浅いお座りの達成であり、深い座位、後脚だけの起立、実機、外乱・センサ誤差への頑健性は未検証。第25回の9動作基盤の学習・成果は、この結果と分けて扱う。CAD、メッシュ、重み、元計測配列、実物写真、メーカー資料、接続情報は含めない。
