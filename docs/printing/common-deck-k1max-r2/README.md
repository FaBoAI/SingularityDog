# 共通底板 r2・Jetsonねじ穴確認・下段ポール固定セット

Jetson側で底板固定ねじの頭が枠に当たる2か所を修正した版です。共通底板を下段の外径20mmカーボンポールへ固定する、既存仕様の上下クランプ4組も同梱しています。全品、黒PLA用です。

## r1からの修正

1. Jetson側の底板固定穴2か所（X=110、Y=±55mm）の上側に、直径8.4mmの開放された逃げを追加しました。M3のねじ頭・外径7mmのワッシャーを置けます。底板の3mm厚と直径3.4mmの貫通穴は保持しています。
2. 以前の別体Jetson棚を床へ固定していた4穴（X=32/122、Y=±42mm）と皿座を埋めました。一体型ではこのねじは不要です。支持座の高さは変えていません。
3. Jetsonの上押さえ用4穴は位置・形状を維持しました。上押さえ、柱、底板を通るM3の軸を確認しています。
4. B26/B27およびB17～B24の印刷形状は従来版と同じです。印刷済みの適合品を再使用できます。新しいクランプを既存クランプに重ねて取り付ける構造ではありません。

Makitaは118×78×60mm・687g、側壁20mm、ベルト2本の既存条件を維持しています。IMU取付穴と上からの工具通路も維持しています。

## 下段カーボンポールへの取り付け

下段ポール2本は前後方向のX軸に沿い、中心はY=±70mm、Z=−60mmです。クランプは各ポールの前後2か所、X=±110mmへ配置します。クランプ内径は公称20.2mm、分割面の設計隙間は0.5mmです。

| 機体位置（+X=前、+Y=左） | 下半分 | 上半分 | 底板と共締めする内側ねじ XY mm | 外側ねじ XY mm |
|---|---|---|---|---|
| 後・右 | B17 | B18 | −110, −55 | −110, −85 |
| 後・左 | B19 | B20 | −110, +55 | −110, +85 |
| 前・右 | B21 | B22 | +110, −55 | +110, −85 |
| 前・左 | B23 | B24 | +110, +55 | +110, +85 |

内側4本は「底板 → 上半クランプ → 下半クランプ → 補強済み本体の脚部」を共締めします。外側4本は「上半クランプ → 下半クランプ → 本体脚部」を締めます。ポールへ穴を開ける必要はありません。下半クランプの下には既存の本体脚部（B02/B04/B06/B08）が必要です。

## ねじ・ナットの寸法案

以下の寸法でCAD上の通路と静的干渉を検査しました。実際に使用するねじ頭・ワッシャー・ナットの寸法に合わせて現物で確認してください。

| 用途 | ねじ・本数 | 上下面ワッシャー | ナット | 設計状態のナット下突出 |
|---|---|---|---|---:|
| 底板＋内側クランプ＋本体脚部 | M3×45、4本 | 外径7／内径3.2／厚0.5mmを各1枚 | M3、二面幅5.5／高さ2.4mmを各1個 | 4.6mm |
| 外側クランプ＋本体脚部 | M3×40、4本 | 同上 | 同上 | 2.6mm |
| Jetson上押さえ＋柱＋底板 | M3×20、4本 | 同上 | 同上 | 約1.1mm |

合計はねじ12本、ナット12個、ワッシャー24枚です。既存の部品を含む必要総数で、すべての買い足しを意味しません。ねじ長さは頭を含まない長さ、頭部は検査用の外径6mm・高さ3mmを仮定しています。IMUや他の機構のねじはこの表に含めていません。

底板の共締めを先に行い、その後Jetsonを取り付けます。Jetson側のねじ頭と機器の外形包絡の横方向余裕は公称0.48mmです。整備時に太い工具を使う場合は、Jetsonを外して作業します。実際のUSBコネクターやケーブルを付けた状態での作業空間は現物確認が必要です。

Jetsonの端は厚さ6.5mm、支持座はZ=−41mmです。上押さえは取り付け時に従来の0.2mmの隙間を詰め、下面Z=−34.5mmで端と柱に接する組立位置として確認しました。押さえの印刷形状は変更していません。これは幾何学的な接触確認で、実機基板の保持力や締付トルクの保証ではありません。実際の端形状・部品配置に合わせて接触箇所を確認し、基板をたわませる締め方は避けてください。

## 確認範囲

出力STLの閉じた形状、部品数、mm寸法、穴の位置と貫通、ねじ頭・軸・ワッシャー・ナットの静的干渉を確認しています。本体側は追加補強版B02/B04/B06/B08の形状で照合しています。

現物の嵌合、PLAの荷重強度・長時間変形、実際の電子部品やUSBプラグとの干渉、脚を全可動域で動かした確認は未実施です。Fusion本体や強化学習用モデルの書き換えは、このSTLセットには含めていません。

寸法の座標はD17 base_linkの組立mm座標です。印刷STLは原点をベッド面へ移したもので、組立座標とは異なります。写真はこのパッケージに含みません。
