# 最新STLの印刷・組立メモ

2026-09-17時点の選定です。[全部材と個別STL](../../stl-parts.md)から、使う部品だけを選びます。黄色44個・黒45個の89個は設計候補の必要数で、実際の印刷済み数や装着済み数ではありません。原写真は収録していません。

単位は**mm・100%**。各STLは印刷姿勢で底面Z=0です。ファイルをまとめたプレートと個別STLを併用して重複印刷しないでください。共通底板r2の11個は[既存公開セット](../common-deck-k1max-r2/README.md)へのリンクを使い、このフォルダーには複製しません。

## 顔の前面クランプ

B40を新しい背面支持枠へ交換し、B42前面リングを追加します。B41は既存のポール上側クランプを再使用します。候補の金物はM3×12mmねじ4本、通常M3ナット4個、外径7・厚さ0.5mmのM3座金4枚です。

前後の支持パッドは各0.3mmを想定しています。ガラス部分の公称すき間2.1mmに、ガラス1.5mmと前後パッドを置く設計です。実際のパッド厚さと圧縮は未検証です。表示領域、基板、USBプラグ、フレキを避け、樹脂のストッパーで位置を決めます。ガタつきをねじの締め増しで消さず、パッドの厚さを調整してください。

## 足先r3の試験と組立

1. [受け側試験片](black/FIT_RECEIVER_SAME_GUIDES_mm.stl)1個、[10mmスペーサー](black/FIT_SPACER_10mm_FOR_M3x20_mm.stl)1個と、[A](black/NUT_CASSETTE_A_FIT_OPTION_mm.stl)・[B](black/NUT_CASSETTE_B_STANDARD_mm.stl)・[C](black/NUT_CASSETTE_C_FIT_OPTION_mm.stl)を各1個印刷します。受け側は本番と同じガイド寸法です。
2. まず標準B（取手の点2個）に、通常のM3六角ナット2個を上から載せます。対辺5.5mm、高さ2.4mmを想定し、ナイロン付きナットは対象外です。
3. 受け側を裏返して2穴面を上にし、ホルダーを水平に保って側面から奥当てまで差します。挿入前のナットは抜け止めされていません。
4. 10mmスペーサーを重ね、M3×20mmねじ2本と厚さ0.5mmのM3座金2枚を通します。スペーサーなしではねじが底に当たります。両方のねじが数回転掛かってから交互に軽く締めます。
5. ナットの空回り、引っ掛かり、底付きがなく、取り外しも繰り返せるか確認します。Bの遊びが大きければA、BがきつければCを比較します。どれも合わなければ本体4個の印刷前に寸法を見直します。
6. 選定したホルダーを4個と、FL/FR/RL/RR本体を各1個用意します。本番では10mm厚の脚側取付部が試験スペーサーに置き換わります。

| ホルダー | 取手の点 | 指部幅 mm | ナット穴の対辺 mm |
|---|---:|---:|---:|
| A | 1 | 8.2 | 5.80 |
| B（標準） | 2 | 8.0 | 5.95 |
| C | 3 | 7.8 | 6.10 |

1脚にM3×20mmねじ、通常M3ナット、M3座金（外径7・厚さ0.5mm）を各2個、4脚に各8個使います。想定する脚厚10mmのとき、ねじ先端と穴底の公称すき間は1.1mmです。実際の脚厚・座金・ナットが違う場合は再確認が必要です。

本体は取付面を下、ホルダーはナット穴を上にして印刷します。内部ガイドの橋渡しは最大約8.8mmです。通路の垂れ・糸引きと、抜けなくなる内部サポートがないことを確認してください。r3ホルダーは旧r2本体に入りません。組立後はホルダーの取手が球面外へ出て、外形は一方向に約52.2mmになります。
