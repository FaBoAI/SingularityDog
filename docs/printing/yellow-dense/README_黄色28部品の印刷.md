## Creality K1での読み込み

1. K1（220×220×250mm）と実際のノズル径・PLAプロファイルを選びます。0.4mmノズルなら0.20mm層を検討の出発点にできます。
2. `PLATE_01…` など**1プレート1ファイル**を100%倍率・mmで読み込み、現在の向きを保ちます。個別28STLと配置済4STLは同じ部品なので、同時に読み込まないでください。
3. 部品の外接枠の間隔は5.2mm、ベッド端から5mm以上です。**脚のフレームは支持材ON**で確認します。支持材・ブリムの外形はSTLに含まず、この5.2mmでは互いに接触する場合があります。重なる場合は部品を減らして別のプレートへ移し、部品の倍率は変えないでください。
4. まだ初回適合確認前なら小カラー1個とD20クランプ1組から試します。初層・支持接続・ナット座・ボルト穴・チューブ内面を積層プレビューで確認してからG-codeを書き出します。

## 姿勢と未確認事項

股リンクは平坦な接地面がある向きに正回転しています。カラーは平置き。残りのリンクは既存の印刷方向を保ち、プレート上ではZ軸回転と平行移動だけで詰めました。元STLの修復、形状変更、左右の鏡映は行っていません。すべて閉曲面・面向き・連結・有限頂点・体積・単位・最低Z=0と配置間隙を確認しています。

平坦な接地面があっても、脚の上部フレームや張り出しには支持材が必要です。5.2mm間隔は部品本体の外接枠の検査であり、支持材の安全な間隔を保証しません。モーターや実チューブとの嵌合、ねじ長さ、締結時の割れ、層間強度・耐荷重、完成実機での動作は未確認です。
