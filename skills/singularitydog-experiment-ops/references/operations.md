# 遠隔実験を継続する

## 起動前と再開時

端末を閉じても続くプロセスとして GPU ホスト側で起動し、端末の接続状態と学習の状態を分ける。同一 GPU を使う処理間では共通ロックを使い、他のジョブのロックや出力を削除して強制起動しない。ロックの保護範囲はそのロックを使うジョブだけで、他の利用者のプロセスまでは制御しない。

公開補助ツールは argv 配列を `shell=False` で実行し、タイムアウトを設定する。新しい job ID のフォルダを一度だけ作り、既存 ID は上書きしない。detach では supervisor の起動成功を返すが、それを学習の起動確認や完了と呼ばず、保存された状態を読み直す。

## 終了と評価への接続

一部のアプリケーションは Python で例外が起きてもアプリ終了処理が exit 0 を返す。内側の完了記録と外側の supervisor の終了記録を比較する。`bounded_job.py` は要求で指定した JSON の値を照合するが、学習器固有のテンソル形状・更新数・重みの転用まで自動で理解するわけではない。必要な値を completion に記録し、その検証を学習側で実装する。

重みの読み出し前後でサイズとハッシュが安定し、要求した最終反復であることを確認する。actor と critic、追加の制御状態を区別し、出力した推論と元の推論の一致を確認する。評価処理へ渡すのは実際に検証した重みのハッシュで、予想したファイル名だけではない。

前の実験の画像や動画は保存してよいが、新しい実験の結果に見せない。完了した有限試験のあと、次の学習を自動で増殖させない。ユーザーが継続を求めている場合は結果を検討し、次の具体的な変更と有限の要求を作る。

## 記録の最小単位

実験 ID、状態、時刻、ソース・入力・親重みのハッシュ、変更した仮説、seed、更新数、観測数、最終反復、実測値、限界、次の一手を残す。公開できないファイルを無理に取り込まず、選択した自作測定値と非公開である範囲を記述する。
