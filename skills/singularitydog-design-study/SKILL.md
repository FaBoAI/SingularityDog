# 設計を学習可能な物理モデルへつなぐ

まず [現在地](../../docs/current-status.md) と [設計の判断基準](references/design-review.md) を読み、既存の成果と未検証の仮説を混ぜない。

1. 部品重量、関節軸、可動域、取り付け、支持姿勢を固定した入力表を作る。購入品の資料は利用者管理の非公開入力とし、この公開リポジトリへ複製しない。
2. 荷重が足から脚、関節支持、フレームへ伝わる経路を描く。外装を荷重部材と数えない。質量はリンク間で二重計上しない。
3. 一度に比較する変数を限定する。脚長、脚幅、姿勢、重量配置、接地点の変更なら、全質量・重心・慣性・関節モーメント・干渉を再計算する。
4. `tools/audit_urdf.py` でリンク木、質量、慣性テンソル、関節定義を検査する。この CPU 検査はメッシュの干渉や実際のエンジン設定を調べない。
5. CAD のネイティブ形状で代表姿勢と実測した問題姿勢を確認し、シミュレータで質量、慣性、関節順、衝突除外、接触設定を読み戻す。
6. 静的候補の順位と、動的学習の評価を分けて記録する。CAD が成立しただけで歩ける・折れないとは判断しない。

Fusion の操作やエクスポートは接続先の実際の機能で実施する。モデル未接続・未取得のときに表示済みと報告しない。取り付けを変えたら、可視形状だけでなく衝突形状と質量特性にも反映する。
