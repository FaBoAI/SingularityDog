# 最初の区間を同じ条件で評価する

[評価プロトコル](references/protocol.md) に従い、方向、seed、時間、始動区間、失敗条件を収録前に固定する。

- リセット前の状態を記録し、最初の転倒・胴体等の接触でそのケースを打ち切る。
- 各方向の世界座標と符号を固定する。体が回ったまま別方向へ進んだ動きを、必要方向への移動と混同しない。
- `tools/evaluate_trace.py` は [共通トレース形式](references/trace-format.md) のデータを集計する。変換時に元配列の名前・座標系・時刻を確認する。サンプル間の値を捏造しない。
- 全脚の足上げ回数を示す。接触情報から離床と着地を確認し、開始前から空中の脚や終了時点で空中の脚を完了した足上げに数えない。
- 動画は元の時間で最初から表示する。成功区間だけの抜粋、再生の高速化、フレームの水増しを成果確認に使わない。
- 要求速度を達成していても、滑り・偏向・後脚の不足・短い試験を明記する。単一 seed の開発動画を正式な実機移行の合格とはしない。

既存の結果を報告する場合は [公開済みスナップショット](../../evidence/progress.json) を参照し、修正前と修正後の結果を混ぜない。
